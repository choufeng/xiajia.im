# 《原则》读书笔记

> 痛苦 + 反思 = 进步。把每次踩坑提炼成一条可执行的原则，人生就从随机游走变成了可迭代的系统。

---

## 关于本书

| | |
|---|---|
| **书名** | 《原则》 |
| **作者** | 瑞·达利欧（Ray Dalio） |
| **首版** | 2017 年 |
| **类型** | 决策系统 / 工作与生活方法论 |

达利欧，全球最大对冲基金桥水的创始人。本书是他把四十年决策经验**规则化**的产物——几百条编号原则，从「拥抱现实」这种元原则，到「5 分钟级会议纪要格式」这种操作原则。

书的起点是 1982 年：达利欧公开预言债务危机，结果**判断反了**，几乎破产，辞退全部员工。这次惨败逼他重建决策系统：不再相信自己的直觉，改用**原则 + 可信度加权**的机器。桥水后来 40 年的年化回报由此而来。

> 工程师视角：这本书本质是把人生活成了 CI/CD——每次失败自动生成一条测试用例（原则），下次决策先跑回归。痛苦是测试红，反思是改代码，进步是下一轮绿。

## 核心框架：机器观

全书的世界观一句话：

> **把自己看作一台机器，你既是里面的工人，也是外面观察、调试这台机器的工程师。**

目标不是「努力工作」，是**改进机器本身**。产出不行时，别对着零件（自己的努力程度）发火，去改设计（流程、原则、人）。

```
目标 → 机器（设计 + 人）→ 产出
                ↑____________|
                  对比差距，改机器
```

## 生活原则：五步流程

达利欧把一切自我改进压成一个循环：

1. **定目标**——清晰的、敢想的
2. **识别问题**——不容忍问题存在（多数人败在这步：容忍 = 舒适地烂着）
3. **诊断根源**——问到不能再问，区分「直接原因」和「根本原因」
4. **设计方案**——绕开根源的路径
5. **执行**——纪律 + 习惯化

> 工程师视角：这就是 debug 循环——目标（预期行为）→ 现象（bug）→ 根因（5 Whys）→ 方案（fix）→ 执行（deploy）。达利欧的贡献是把「不容忍问题」显式列为一步：**容忍已知 bug 是最大的反模式**，人生同理。

## 生活原则：两大障碍——自我与盲点

为什么明知该反思还是做不到？达利欧给出两个生理级解释：

- **自我障碍**：大脑把「观点被挑战」识别为「生存被威胁」，启动防御而非思考
- **盲点障碍**：你天生的思维方式决定了有些角度你**看不见**——不是不愿，是不能

解法：**极度头脑开放**——把「我对不对」的执念换成「怎么知道我是对的还是错的」的实验心态。具体操作：

- 陈述观点时挂上可信度：「我 70% 确信」而非斩钉截铁
- 找最强反对者：**最好的问题不是「你怎么看」，而是「你觉得我的想法哪里错」**
- 区分「提问」和「挑战」：把所有发言者的默认意图假设为求真，而非求胜

> 工程师视角：自我障碍 = 「不是我代码的问题」综合症。工程界的成熟解法达利欧早写了：code review 不是审判作者，是让盲点暴露。**可信度挂声明 = 给观点标注置信区间**；找最强反对者 = 主动邀请红队。

## 工作原则：创意择优

桥水的组织操作系统，三件套：

1. **极度透明**：会议公开、批评当面、纪要全员可查——让信息不对称消失，谎言无处存活
2. **极度真实**：任何人对任何人可以说「你这个判断不行」，职级不豁免
3. **可信度加权**：观点不一时不数人头、不看职级，按**发言者在该领域的战绩**加权——桥水连「谁擅长什么」都用数据打分（棒球卡系统）

创意择优 = 激进版 open source 治理：fork 谁、merge 谁，由 commit 历史说话，不由职位说话。

> 工程师视角：可信度加权 = **以 code review 通过率和线上事故记录说话**，而不是以 title 说话。极度透明 = 全员可读的 incident 复盘 + 无 blame culture 的前身。代价也诚实：透明到残酷的文化，离开率极高——系统吞吐换了人员损耗，达利欧没回避这一点。

## 我的三个提醒

1. **别全盘照抄桥水。** 极度透明需要极强的人员筛选做前提，普通团队直接上 = 公开处刑。先抄「可信度加权」和「写原则」这两个低毒性组件。
2. **原则要写到可执行。** 「多倾听」不算原则，「重大决策前先问最反对的人『哪里错』」才算。检验标准：能否编译成 if-then。
3. **每年重写。** 原则是快照不是圣典——达利欧自己改了四十年。坚持「发现更好的就更新」这一条元原则即可。

> 一句话总结：把人生当系统维护——失败自动转测试用例，观点挂置信区间，决策按可信度加权。四十年的超额收益，只是这套系统的副产品。
