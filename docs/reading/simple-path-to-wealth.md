# 《简单致富》读书笔记

> 致富的路径可以简单到一句话：攒钱，买入全市场指数基金，然后什么都不做。难的从来不是方法，是「什么都不做」。

---

## 关于本书

| | |
|---|---|
| **书名** | 《简单致富》（*The Simple Path to Wealth*） |
| **作者** | JL 柯林斯（JL Collins） |
| **首版** | 2016 年（前身是 2011 年起的博客系列） |
| **类型** | 个人理财 / 指数投资 |

柯林斯不是华尔街人，是个普通生意人。这本书的起点是女儿上大学前，他发现自己一辈子攒下的理财认知没处传承，于是写成一封封长信，后来集结成书。核心卖点只有一个：**给不想研究投资的人一套可以直接照抄的方案**，并且解释清楚为什么这套方案有效。

全书立场与博米尔·巴菲特遗嘱里的那句话同款：普通人最好的投资，就是低成本指数基金 + 时间。柯林斯把这句话展开成了一本操作手册。

> 工程师视角：这本书和本站其他理财笔记构成互补——《金钱心理学》管「为什么做不到」（行为），《够了》管「为什么值得」（哲学），《投资者的未来》管「为什么指数有效」（数据），这本管「具体怎么做」（操作手册）。四本里它最薄、最直接、也最可执行。

## 核心框架：F-you Money → 财富自由

柯林斯的全书逻辑是一条单行道，五步走完：

```
避免消费债 → 存钱率拉高 → 攒出 F-you Money → 继续攒到财富自由 → 指数基金躺着不动
```

### 第一步：先掐死消费债

信用卡债、车贷、分期——年化 15%~25% 的消费债，是数学上的必输局。**没有任何投资能稳定跑赢 20% 的债务利息。** 柯林斯的排序很硬：有消费债，先还债，别的都免谈。

> 工程师视角：消费债 = 技术债里利息最高的那种。带着年化 20% 的债去「投资」，等于带着内存泄漏去谈性能优化——先堵漏，再谈其他。

### 第二步：存钱率是唯一杠杆

收入减支出 = 储蓄。多数人盯着分子（收入），柯林斯盯着两件事：

- **收入提升后，支出不跟着提升**——每一次加薪都是存钱率的跳板，不是生活方式的升级券
- **存钱率决定自由的速度是超线性的**——存 50% 的人，一年攒下的钱够花一年；存 10% 的人要干十年才攒出一年

这就是「F-you Money」的由来：**攒出一笔够你裸辞两年不慌的钱，你对老板、对烂工作、对烂客户就有了说「不」的底气。** 这笔钱买的不是利息，是选择权。

> 工程师视角：F-you Money = 系统的冗余容量。没有冗余的系统，任何一次故障都是灾难；没有 F-you Money 的打工人，任何一次裁员都是绝境。冗余不是浪费，是生存能力。

### 第三步：钱放哪——全市场指数基金

到了投资环节，柯林斯给出的方案简单到令人不安：

- **买全市场指数基金**（书里以美股为例是 VTSAX，沪深/A 股投资者可对应全市场宽基 ETF）
- **持续买入，不做波段，不选股，不择时**
- **把市场崩盘视为正常天气，甚至是打折促销**

支撑这个「简单」的论证链条：

| 诘问 | 柯林斯的回答 |
|------|-------------|
| 为什么不选股？ | 主动选股者长期跑赢指数的比例极低，且事先无法识别谁是幸存者 |
| 为什么不择时？ | 市场最佳交易日大多紧挨着最差交易日，躲开暴跌的人同时躲开了暴涨 |
| 为什么指数能赢？ | 指数 = 整个市场的平均收益，而费前平均必然被费用拉到平均以下 |
| 崩盘怎么办？ | 历史上每次崩盘都收复失地；时间是指数投资唯一的护城河 |

费用的杀伤力他算得极狠：**1% 的年费，三十年后吃掉你约 25% 的最终财富。** 指数基金胜出的第一原因不是「聪明」，是「便宜」。

> 工程师视角：选主动基金 = 把系统托管给一个你无法 review 的黑盒，还要付托管费；买指数 = 直接订阅「整个市场」这个接口，SLA 由历史数据背书。简单路径的本质是**减少决策面**——每次主动决策都是一次引入 bug 的机会。

### 第四步：崩盘是礼物

全书情绪价值最高的一章。柯林斯历数 1929、1973、2000、2008——每次跌 50% 上下，每次都有人喊「这次不一样」，每次市场都创了新高。结论：

- **崩盘不是系统故障，是系统的正常呼吸**
- 持续买入者在崩盘里是在低价扫货，「市场下跌 = 你买的每份指数更便宜」
- 真正危险的只有两种人：加杠杆的、底部割肉的

> 工程师视角：崩盘 = 流量洪峰。系统设计里你不会为「永远没有洪峰」做规划，而是保证洪峰来了不挂。投资里的「洪峰冗余」就是不加杠杆、不拿短期要用的钱进场。扛得住，才谈得上等得起。

### 第五步：4% 法则，定义「够了」

钱攒到多少算财务自由？柯林斯引用三位一体研究（Trinity Study）的结论：**按每年不超过总资产 4% 支取，投资组合在绝大多数 30 年周期里不会耗尽**（美股历史数据下）。反过来算：

```
年支出 × 25 = 自由线
年花 20 万 → 攒够 500 万 → 之后的每一天，工作变成选项而非义务
```

4% 不是精确承诺，是量级估算。它的真正价值是**把「自由」从一个情绪词变成一个数字**——你知道终点在哪，才知道还剩多远。

> 工程师视角：这就是给「够了」做容量规划。没有容量数字的项目永远在加需求，没有自由线的收入永远在焦虑。先定 SLA，再谈架构——人生同理。参见《够了》笔记：知道数字在哪的人，才有资格提前说停。

## 全书浓缩：一页纸方案

柯林斯自己也承认，全书可以直接压成一张卡片：

1. 消费债 → 清零，之后不再碰
2. 存钱率 → 尽可能高，加薪不加支出
3. F-you Money → 先攒 6~24 个月支出
4. 投资 → 全市场指数基金 + 定投 + 不动
5. 崩盘 → 视为促销，继续买
6. 终点 → 年支出 × 25，之后按 4% 支取

## 我的三个提醒

1. **简单路径不等于无脑路径。** 柯林斯的方案隐含一个强前提：美股式「长期向上 + 宽基指数」市场环境。换市场、换时代，标的不变，精神不变——低成本、宽分散、少操作——但具体载体要自己校准。
2. **最难的环节在第 0 步：开始。** 大多数人死在「再研究研究」，而研究十年的人收益不如第一天就定投的人。这个领域的知识收益曲线极其陡峭：前 10% 的认知贡献 90% 的结果。
3. **F-you Money 的意义超过钱本身。** 它改变你和一切不对等关系的谈判位。哪怕永远不退休，这笔钱也已经每天都在发挥作用。

> 一句话总结：致富这件事，复杂是卖点，简单是路径。所有人都有能力走完这条简单路径，只是大多数人不信——不信，恰好是这条路径有效的部分原因。
