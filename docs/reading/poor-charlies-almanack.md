# 《穷查理宝典》读书笔记

> 想变聪明？反过来想，总是反过来想。避免所有让自己变蠢的事，剩下的就是聪明。

---

## 关于本书

| | |
|---|---|
| **书名** | 《穷查理宝典》（*Poor Charlie's Almanack*） |
| **作者** | 彼得·考夫曼 编（主角：查理·芒格） |
| **首版** | 2005 年 |
| **类型** | 演讲集 / 多元思维 / 投资哲学 |

芒格是伯克希尔·哈撒韦副董事长，巴菲特背后五十年的搭档。本书不是专著，是芒格历次演讲 + 传记 + 《芒格主义》语录的合集，核心是三场演讲：哈佛《论_BASIC/人类误判心理学》、南加州大学《论基本的、普世的智慧》。

与《纳瓦尔宝典》同一体裁——语录与长谈，只是主角从硅谷投资人换成九十岁的奥马哈老律师。区别：纳瓦尔讲杠杆与幸福，芒格讲**心智模型与避坑**。

## 核心框架：格栅思维

芒格的方法论一句话：**在大脑里装一张由多学科基础模型组成的格栅，任何问题都让多个模型同时过一遍。**

| 学科 | 借用的核心模型 |
|------|--------------|
| 数学 | 复利、概率、排列组合、大数 |
| 心理学 | 激励偏差、社会认同、损失厌恶 |
| 物理/生物 | 临界质量、进化、适者生存 |
| 经济 | 机会成本、比较优势、规模效应 |
| 历史 | 周期、路径依赖 |

单一模型是灾难：**「手里拿锤子的人，看什么都像钉子。」** 工程师尤其危险——技术模型太好用，容易拿它敲一切非技术问题。

## 逆向思维：避免愚蠢 &gt; 追求聪明

芒格反复引用数学家雅可比的话：「Invert, always invert（反过来想，总是反过来想）」。

- 想知道如何幸福？先研究人是怎么毁掉自己人生的（嫉妒、怨恨、报复、自怜），然后终身避开
- 想知道如何投资成功？先列出所有亏钱的方式——加杠杆、追热点、不懂装懂、频繁交易——然后绝不碰
- 他在演讲里真的发过「人生药方」：如何保证痛苦——迟到早退、不兑现承诺、只从自己经验学习、遭遇挫折就躺平

> 工程师视角：这就是防御性编程 + 故障模式分析（FMEA）。先枚举系统怎么挂，逐条加防护。芒格是把 FMEA 用在人生决策上——**查错表思维比聪明更可靠**，因为聪明会失灵，清单不会。

## 能力圈：知道边界在哪

> 「如果你不知道自己的能力圈边界，那它就不算能力圈。」

芒格和巴菲特几十年不碰科技股，不是不懂，是**承认不懂**。机会成本逻辑：错过不属于你的机会不算损失，跨出边界下注才算。

> 工程师视角：能力圈 = 系统的 SLA 边界。接口没承诺的事，别在调用方赌它会做。芒格的纪律就是：超出契约的行为，收益再高也是Undefined Behavior。

## 人类误判心理学：25 种认知开关

哈佛演讲是全书最硬的一章。芒格列出 25 种让人系统性犯蠢的心理倾向，几乎全是《思考，快与慢》的民间先声：激励偏差（「别问理发师你需不需要理发」）、社会认同、承诺一致性、剥夺超级反应（损失厌恶）、权威错误影响……

他的洞见：这些开关单独失效有限，**多个开关同向叠加时会产生 Lollapalooza 效应**——理性彻底宕机。拍卖、传销、泡沫，都是多开关共振的产物。

> 工程师视角：单一故障系统通常扛得住，**复合故障才是大事故的常态**。人脑的可用性设计同理：识别自己正处在几个开关同时触发的场景（群情激奋 + 锚定 + 承诺升级），先离场再说。

## 投资观：坐等的力量

芒格把伯克希尔的成功浓缩为：**「我们靠不行动赚钱。」**

- 好机会极少，来临时下重注，其余时间拿现金等
- 「用合理价格买伟大公司，远好于用便宜价格买平庸公司」——是他把巴菲特从捡烟蒂路上掰过来的
- 财富 = 少数几个大决策 × 坐得住

与《简单致富》互证：柯林斯给普通人方案（指数躺平），芒格给专业者纪律（极少出手，出手要狠）。

## 我的三个提醒

1. **格栅不是收藏夹。** 每个模型要问到能解释一个你亲历的案例，才算装进格栅。只是「知道名词」等于没装。
2. **误判清单要随身。** 25 条不用背，遇大决策时过一遍：我现在被哪个开关按住了？
3. **芒格的底气来自阅读量。** 「我这辈子遇到的聪明人，没有一个不每天阅读的——没有，一个都没有。」格栅模型本身就是读出来的。

> 一句话总结：别人研究怎么赢，芒格研究怎么不输。把失败方式列全并终身避开，剩下的时间复利自动完成剩下的工作。
