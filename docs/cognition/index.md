# 认知提升

> 大脑出厂设置不完美。它跑得快，但常常跑偏——这套栏目就是给思维装一面镜子。

---

## 为什么开这个栏目

我们每天都在想、在判断、在争论，却很少检查「想法本身是怎么产生的」。结果就是：**同样的事实，不同的人看出完全不同的结论；同一个人，换个心情结论就翻面。**

这不是智力问题，是**大脑的工作机制问题**。认知心理学几十年研究早就告诉我们：人脑有一整套省电的「快捷回路」，快是真快，但它会系统性、可预测地犯错。这些错误有名字、有规律、有破解法。

这个栏目不灌鸡汤，只做一件事：

> **把一个个思维陷阱拆出来，看清它的长相，记住它的名字，学会在它出现的瞬间喊停。**

谬误一旦被命名，它对你的控制力就掉了一大半。你没法防御一个你没意识到的东西，但你能轻松躲开一个你知道名字的东西。

## 内容定位

每篇聚焦一个具体的思维陷阱或逻辑谬误，固定结构：

| 模块 | 作用 |
|------|------|
| 一句话定义 | 先记住它是什么 |
| 它长什么样 | 用生活/工作中的真实例子认脸 |
| 为什么会犯 | 心理机制，知其所以然 |
| 怎么识别与破解 | 能立刻用的招 |
| 工程师视角 | 把抽象谬误拉回代码评审、技术决策的现场 |
