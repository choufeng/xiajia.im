# 认知提升

> 大脑出厂设置不完美。它跑得快，但常常跑偏——这套栏目就是给思维装一面镜子。

---

## 为什么开这个栏目

我们每天都在想、在判断、在争论，却很少检查「想法本身是怎么产生的」。结果就是：**同样的事实，不同的人看出完全不同的结论；同一个人，换个心情结论就翻面。**

这不是智力问题，是**大脑的工作机制问题**。认知心理学几十年研究早就告诉我们：人脑有一整套省电的「快捷回路」，快是真快，但它会系统性、可预测地犯错。这些错误有名字、有规律、有破解法。

这个栏目不灌鸡汤，只做一件事：

> **把一个个思维陷阱拆出来，看清它的长相，记住它的名字，学会在它出现的瞬间喊停。**

谬误一旦被命名，它对你的控制力就掉了一大半。你没法防御一个你没意识到的东西，但你能轻松躲开一个你知道名字的东西。

## 内容定位

每篇聚焦一个具体的思维陷阱或逻辑谬误，固定结构：

| 模块 | 作用 |
|------|------|
| 一句话定义 | 先记住它是什么 |
| 它长什么样 | 用生活/工作中的真实例子认脸 |
| 为什么会犯 / 为什么被忽视 | 心理机制，知其所以然 |
| 怎么识别与破解 | 能立刻用的招 |
| 工程师视角 | 把抽象概念拉回代码评审、技术决策的现场 |

## 已收录

### 逻辑谬误

- [稻草人谬误](./strawman-fallacy) — 别替对方编一个弱版观点，再去打它
- [红鲱鱼谬误](./red-herring-fallacy) — 别被无关话题带偏了主线
- [归因谬误](./attribution-fallacy) — 别急着找「就是因为他这人」
- [滑坡谬误](./slippery-slope-fallacy) — 别把「可能」说成「必然」的一连串灾难
- [诉诸人身谬误](./ad-hominem) — 「他不行」推不出「他错」，先拆论证再看人

### 风险与不确定性

- [黑天鹅事件](./black-swan) — 预测不来的事，往往才是改变一切的事
- [灰犀牛事件](./grey-rhino) — 真正毁掉你的，是明明看到却没动手
- [林迪效应](./lindy-effect) — 已存活越久的东西，预期还能活越久

### 自我认知

- [达克效应](./dunning-kruger-effect) — 越菜越自信，越懂越谦虚
- [幸存者偏差](./survivorship-bias) — 你看到的，只是没被筛掉的那一部分

### 决策与判断

- [锚定效应](./anchoring-effect) — 第一个数字，绑架了你后面所有的判断
- [代表性启发](./representativeness-heuristic) — 用「像不像」判断「是不是」，忘了先问基数
- [前景理论](./prospect-theory) — 输赢不在账上，在参照点上；亏的痛是赚的乐的两倍
- [沉没成本谬误](./sunk-cost-fallacy) — 都投这么多了，不是停的理由
- [禁果效应](./forbidden-fruit-effect) — 越说不行，越想要：禁令本身就是广告

### 群体与社会

- [回音室效应](./echo-chamber) — 一群人都同意你，不代表你对
- [旁观者效应](./bystander-effect) — 人越多，越没人出手

> 认知提升不是变聪明，是**变清醒**：知道自己会在哪里栽跟头，于是提前绕开。
