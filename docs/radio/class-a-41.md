## 第 401 题

<span data-tts-skip><em>MC1-0574 · 单选 · 适用 A 类</em></span>

收发信机设置静噪功能的目的是什么？

:::tip 正确答案
**在没有信号的情况下关闭音频输出，避免播放刺耳的噪声**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 在没有信号的情况下关闭音频输出，避免播放刺耳的噪声 ✓
- B. 滤除所收信号中的噪声，使对方的话音变得清晰
- C. 滤除发信方的环境噪声，使发出的话音更为清晰
- D. 自动控制收信机的增益，避免信号过强时发生阻塞或失真

正确答案：A

</details>

**题解**

****1. 相关知识点解释****
静噪功能（Squelch）是业余无线电设备中常见的接收机控制功能，主要用于在无有效信号接收时关闭音频输出。其核心作用是抑制背景噪声（如热噪声、射频干扰等），避免在无通信时产生刺耳的“白噪声”干扰操作者。

静噪的实现依赖于对信号强度或载波频率的检测：  
- 当接收机检测到信号强度高于设定阈值时，静噪功能解除，音频输出开启；  
- 当信号强度低于阈值时，音频输出被强制关闭。  
这一功能在FM通信中尤为重要，因其调制特性易受低信噪比影响。

****2. 解题思路与分析过程****
**题目关键词**：静噪功能、信号、噪声、音频输出。  
**核心逻辑**：  
- 静噪功能属于**接收机控制**，与发射机（发信方环境噪声）无关，可排除第三个选项。  
- 静噪功能**不直接滤除信号中的噪声**（需其他技术如DSP降噪），而是通过关闭音频输出间接消除无信号时的背景噪声，因此第二个选项错误。  
- 自动增益控制（AGC）是接收机另一功能，用于动态调整增益以适应信号强度变化，与静噪无直接关联，第四个选项错误。  
- 唯一正确逻辑：静噪功能在无信号时关闭音频输出，避免噪声干扰。

****3. 答案分析****
- **第一个选项**（在没有信号的情况下关闭音频输出，避免播放刺耳的噪声）：  
  正确。符合静噪功能的定义，直接描述其作用。  
- **第二个选项**（滤除所收信号中的噪声，使对方的话音变得清晰）：  
  错误。此为降噪（Noise Reduction）功能，如DSP滤波，与静噪无关。  
- **第三个选项**（滤除发信方的环境噪声，使发出的话音更为清晰）：  
  错误。发信方环境噪声属于发射机输入端问题，需通过发射机音频处理解决，与接收机静噪无关。  
- **第四个选项**（自动控制收信机的增益，避免信号过强时发生阻塞或失真）：  
  错误。此为自动增益控制（AGC）功能，属于接收机另一独立模块。

****4. 知识库引用****
- **No-Nonsense Technician Class License Study Guide**：  
  文档中明确提到静噪控制的作用是“mute the receiver audio unless you are receiving a signal above a set signal strength”（接收信号低于设定阈值时关闭音频输出）。  
  同时在T4B03中讨论了如何调整静噪阈值以接收弱信号，进一步验证其核心功能为无信号时关闭输出。

**最终答案**：  
**在没有信号的情况下关闭音频输出，避免播放刺耳的噪声**。

:::

<details>
<summary>查看全部选项</summary>

- A. 此类电路根据接收机鉴频输出的高音频噪声的大小来判断信号消失与否，并据此控制音频输出。这种检测需要一定的时间才能完成，这导致短暂泄漏刺耳的噪声 ✓
- B. 该噪声是发射台话筒的 PTT 键接点跳动所致，发射到接收端时还可能带有“叮”的声音
- C. 该噪声是发射台的一种有目的所为，例如是用作结束发射的标志，有时是“嘟”的声音
- D. 这是由接收机的自动增益电路的时间常数造成

**题解**

**1. 相关知识点解释**
- **静噪功能（Squelch）**：用于抑制接收机在无信号时的背景噪声。当检测到信号消失后，静噪电路需要一定时间延迟才能关闭音频输出。
- **鉴频器（Discriminator）**：用于解调FM信号，其输出包含音频信号和噪声分量。
- **PTT（Push-to-Talk）**：按键通话开关，松开PTT后发射机停止发送信号。
- **自动增益控制（AGC）**：调整接收机增益以保持输出信号幅度稳定，但其时间常数主要影响信号强度变化时的响应速度。

**2. 解题思路与分析过程**
- **关键矛盾点**：噪声拖尾出现在信号结束后的瞬间，需判断其来源是电路响应延迟还是发射端设计。
- **选项分析**：
  - **第一个选项**：直接关联静噪延迟与噪声泄漏。当信号消失时，鉴频器输出的高音频噪声增加，静噪电路需时间检测并关闭音频，导致短暂噪声泄漏。
  - **第二个选项**：PTT接点跳动可能产生瞬态噪声，但此类机械抖动更可能表现为“叮”声而非连续的“嘶”声，且与静噪功能无直接关联。
  - **第三个选项**：故意设计的结束标志音通常为明确的“嘟”声，非短促刺耳的噪声。
  - **第四个选项**：AGC时间常数影响增益恢复速度，但噪声拖尾与信号消失瞬间的音频输出控制无关。

**3. 答案选择原因**
- **正确答案**：**第一个选项**（此类电路根据接收机鉴频输出的高音频噪声的大小来判断信号消失与否，并据此控制音频输出。这种检测需要一定的时间才能完成，这导致短暂泄漏刺耳的噪声）。
- **依据**：静噪电路的噪声检测存在时间延迟，导致信号结束后仍有一段短暂的噪声输出。这是FM接收机静噪功能的典型特性，符合题目描述的“嘶”或“喀拉”声。

  - 自动天线调谐功能通常标记为 **ATU** 或 **Tuner**，与音量控制无关。

- **VOL** 是国际通用的音量控制标识，在收发信机中直接对应接收音频输出的调节功能。  
- 其他选项涉及的功能（如语音压缩、前置放大、自动天线调谐）均有独立且明确的术语标识，与 **VOL** 无关。

## 第 409 题

<span data-tts-skip><em>MC2-0582 · 多选 · 适用 A 类</em></span>

亚音和数字亚音静噪技术都是在调频发射机所发射的语音信号上附加一个人耳不易察觉的低频信号并用来选通接收机的静噪。它们所对应的收发信机设置菜单项有：

:::tip 正确答案
**CTCSS**<span data-tts-skip>（A）</span> · **DCS**<span data-tts-skip>（B）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. CTCSS ✓
- B. DCS ✓
- C. DTMF
- D. SQL

正确答案：A、B

</details>

**题解**

**1. 知识点解释**
**亚音（CTCSS）与数字亚音（DCS）静噪技术**：  
- **CTCSS**（Continuous Tone-Coded Squelch System）：通过在调频语音信号上附加一个**低频模拟音频信号**（如67.0Hz~250.3Hz），接收机仅在检测到匹配的亚音信号时才解除静噪，实现多组用户共享同一频段而不互相干扰。  
- **DCS**（Digital Coded Squelch）：采用**数字编码序列**（如023、047）替代模拟音频，原理与CTSS类似，但抗干扰能力更强，属于数字亚音技术。  
- **SQL**（Squelch）：普通静噪功能，用于手动/自动抑制无信号时的噪声，与亚音无关。  
- **DTMF**（Dual-Tone Multi-Frequency）：双音多频信号，用于遥控或拨号指令，如切换信道或激活中继，不参与静噪选通。

**2. 解题思路**
题目要求选择**与亚音和数字亚音静噪技术直接对应的菜单项**：  
- **CTCSS**和**DCS**分别对应模拟和数字亚音技术，直接用于静噪选通。  
- **DTMF**虽为音频信令，但用于控制而非静噪选通；**SQL**是静噪功能的基础设置，不涉及亚音编码。  

**3. 答案分析**
- **CTCSS**：正确。对应模拟亚音静噪技术。  
- **DCS**：正确。对应数字亚音静噪技术。  
- **DTMF**：错误。属于信令技术，用于远程控制。  
- **SQL**：错误。是静噪功能的基础设置，与亚音无关。  

**4. 结论**
**正确答案：CTCSS、DCS**  
亚音和数字亚音静噪技术通过**CTSS**（模拟低频信号）和**DCS**（数字编码）实现接收机静噪选通，而**DTMF**和**SQL**不直接参与该技术。
