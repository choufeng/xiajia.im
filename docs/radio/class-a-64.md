**题解**

在做题或工程估算时，有一个非常经典的“加3乘2，加10乘10”的速记规律，基准是

 $0\text{ dBm} = 1\text{ mW}$：$0\text{ dBm} = 1\text{ mW}$

加 10dB 等于功率乘以 10 $\rightarrow$ $10\text{ dBm} = 10\text{ mW}$

再加 10dB 等于功率再乘以 10 $\rightarrow$ $20\text{ dBm} = 100\text{ mW}$

再加 10dB 等于功率再乘以 10 $\rightarrow$ $30\text{ dBm} = 1000\text{ mW} = 1\text{ W}$

现在我们得到了 $30\text{ dBm} = 1\text{ W}$，

接下来利用“加 3dB 等于功率乘以 2”：$30\text{ dBm} + 3\text{ dB} = 33\text{ dBm} \rightarrow 1\text{ W} \times 2 = 2\text{ W}$ 

$33\text{ dBm} + 3\text{ dB} = 36\text{ dBm} \rightarrow 2\text{ W} \times 2 = 4\text{ W}$

此时 36dBm 对应 4W，5W 稍微大一点点，因此在选项中最接近且符合标准计算的就是 37dBm。

电源两端电动势的方向为：

**从电源的负极到正极**<span data-tts-skip>（A）</span>

- D. 与电源的电压方向相同

正确答案：A

</details>

**题解**

**1. 知识点解释**
电动势（Electromotive Force, EMF）是电源将其他形式的能量转化为电能的能力，其方向定义为**电源内部非静电力移动正电荷的方向**。根据物理学基本原理：  
- **电动势的方向**：在电源内部，电动势的方向是从低电势（负极）指向高电势（正极），即**从负极到正极**。  
- **外电路电流方向**：常规电流方向是从正极到负极，但这是电荷流动的方向，而非电动势的方向。  
- **电压方向**：电压（电势差）的方向定义为从高电势到低电势，与电动势方向相反。

**2. 解题思路**
- **分析选项**：  
  - **选项1**：符合电动势方向的定义（从负极到正极）。  
  - **选项2**：描述的是外电路电流方向，而非电动势方向。  
  - **选项3**：负载电阻和内阻的相对大小影响电路中的电流和端电压，但不会改变电动势的方向。  
  - **选项4**：电压方向是从正极到负极，与电动势方向相反，因此错误。

- **知识库引用**：  
  根据《No-Nonsense Technician Class License Study Guide》中关于电动势方向的描述：  
  > “在电源内部，电动势的方向是由低电势（负极）指向高电势（正极）”。

**3. 答案分析**
**正确答案**：从电源的负极到正极。  
- **选项1**：正确。电动势方向在电源内部从负极到正极，符合物理定义。  
- **选项2**：错误。此为外电路电流方向，而非电动势方向。  
- **选项3**：错误。负载和内阻仅影响电流大小和端电压，与电动势方向无关。  
- **选项4**：错误。电压方向（正极到负极）与电动势方向相反。  

**4. 结论**
题目考查电动势方向的基本定义，需明确区分电动势、电流方向和电压方向的不同物理意义。  
**最终答案**：从电源的负极到正极。

- D. 与电源的电动势方向相同

**题解**

**1. 相关知识点解释**
**电源两端电压的方向**与**电动势方向**是两个相关但不同的概念：
- **电压方向**（电势差方向）：定义为从高电势指向低电势，即从正极到负极。
- **电动势方向**：在电源内部规定为从负极到正极（非静电力克服电场力做功的方向）。
- **端电压**：实际电源在闭合回路中提供的电压，其方向仍由正极指向负极，而电动势方向始终从负极到正极。

**2. 解题思路与分析**
- **选项一**（从电源的正极到负极）：  
  这是电压方向的定义，符合电势差的物理意义。电源两端电压的方向即从高电势（正极）指向低电势（负极），因此该选项正确。
  
- **选项二**（从电源的负极到正极）：  
  这是电动势的方向，而非电压方向。电压方向与电动势方向相反，因此该选项错误。

- **选项三**（取决于负载电阻和电源内阻的相对大小）：  
  端电压的大小受负载电阻和内阻影响（如 $ U = E - Ir $），但方向始终由电源极性决定，与内阻或负载无关。因此该选项错误。

- **选项四**（与电源的电动势方向相同）：  
  电动势方向从负极到正极，而电压方向从正极到负极，二者方向相反。因此该选项错误。

**3. 答案分析**
**正确答案**：**从电源的正极到负极**  
**原因**：  
- 电压方向是电势降低的方向，即正极指向负极（选项一正确）。  
- 电动势方向（从负极到正极）与电压方向相反（排除选项二、四）。  
- 端电压方向仅由电源极性决定，与负载或内阻无关（排除选项三）。

**引用知识库**
- **文档名称**：No-Nonsense Technician Class License Study Guide  
- **章节信息**：Electrical principles（电学基本概念部分）  
  文档中明确指出电流方向和电压的关系，强调电池电压方向（直流电源）为正极到负极，而电动势方向与之相反。

**题解**

**题解：可充电电池类型判断**

**1. 知识点解释**
- **可充电电池（二次电池）**：通过化学反应可逆化实现多次充放电的电池，常见类型包括**锂离子电池**、**铅酸电池**、**镍镉电池**等。
- **不可充电电池（一次电池）**：化学反应不可逆，使用后需丢弃，如**碱性干电池**（碱性锌锰电池）。
- **钠离子电池**：近年来发展的新型二次电池，原理与锂离子电池类似，属于可充电电池范畴。

**2. 解题思路与分析过程**
- **选项逐一分析**：
  1. **锂离子电池**：核心可充电电池技术，广泛用于消费电子和新能源汽车（文档引用：《No-Nonsense Technician Class License Study Guide》明确列举为可充电电池）。
  2. **钠离子电池**：基于钠离子嵌入/脱出反应的二次电池，近年在储能领域应用增多（知识补充：其原理与锂离子电池一致，属于可充电电池）。
  3. **铅酸电池**：传统可充电电池，用于汽车启动电源等场景（文档引用：同上文献明确提及）。
  4. **碱性干电池**：典型的不可充电电池（文档引用：同上文献提到碳锌电池不可充电，碱性干电池同属一次电池）。

- **判断逻辑**：  
  根据化学反应可逆性及实际应用场景，前三者为可充电电池，碱性干电池为不可充电。

**3. 答案分析**
**正确答案**：锂离子电池、钠离子电池、铅酸电池  
**错误答案**：碱性干电池  

**选项解析**：
1. **锂离子电池**：符合可充电定义，正确。
2. **钠离子电池**：新型二次电池，正确（需注意部分考试可能未更新此知识点，但根据科技发展趋势应认可）。
3. **铅酸电池**：经典可充电电池，正确。
4. **碱性干电池**：属于一次电池，不可充电，错误（文档明确支持该结论）。
