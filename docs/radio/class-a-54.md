:::tip 正确答案
**直接变换（Direct-Conversion），即接收到的射频信号在解调之前不做频率变换**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 直接变换（Direct-Conversion），即接收到的射频信号在解调之前不做频率变换 ✓
- B. 直流（Direct Current），指直流电源供电的收信机
- C. 介质电容（Dielectric Capacitor），指收信机中用于调谐的电容器所用的特定介质
- D. 数字变频（Digital-Conversion），指接收到的射频信号经过了数字化的变频处理

正确答案：A

</details>

**题解**

****1. 相关知识点解释****
本题考查对**DC式收信机**中“DC”缩写含义的理解。  
- **超外差式收信机**：传统接收机架构，通过将射频信号（RF）先变频为固定中频（IF），再进行滤波和解调。  
- **DC式收信机**（Direct-Conversion Receiver）：直接将射频信号转换为基带信号（零中频），无需中频步骤。其核心是**同相正交解调**（IQ Demodulation），通过本地振荡器（LO）与射频信号直接混频，输出I（同相）和Q（正交）两路基带信号。  

****2. 解题思路与分析过程****
1. **排除无关选项**：  
   - **直流（Direct Current）**：指电源类型，但“DC式收信机”描述的是信号处理方式而非供电形式，排除。  
   - **介质电容（Dielectric Capacitor）**：与调谐电路相关，但题目强调工作原理，排除。  
   - **数字变频（Digital-Conversion）**：涉及数字化处理（如软件定义无线电SDR），但“DC”在此语境下不指代数字技术，排除。  

2. **确定正确选项**：  
   - **直接变换（Direct-Conversion）**：符合“DC”在通信技术中的专业定义，即射频信号直接下变频到基带，无需中频阶段。  

****3. 答案分析****
- **正确答案**：直接变换（Direct-Conversion）  
  - **原因**：  
    - DC式收信机的核心是**零中频架构**（Zero-IF），通过直接混频消除中频环节，简化电路设计。  
    - 该技术需解决**镜像频率干扰**和**DC偏移**（DC Offset）问题，但因其结构简单、成本低，广泛应用于现代通信（如软件定义无线电）。  

****4. 扩展知识（关键点）****
- **直接变换的优势**：  
  - 无需中频滤波器，减少硬件复杂性。  
  - 支持宽频带信号处理，适应多模通信需求。  
- **挑战**：  
  - 本地振荡器需精确匹配射频频率，否则导致IQ信号失真。  
  - 需校正DC偏移（如由LO泄漏引起）。

<span data-tts-skip><em>MC1-0838 · 单选 · 适用 A/B/C 类</em></span>

接收机和发射机中常见的混频器有什么作用？

:::tip 正确答案
**频率变换。将信号的原始频率变换成另一个频率**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 频率变换。将信号的原始频率变换成另一个频率 ✓
- B. 混合式调音。将两个信号相互叠加，送往扬声器
- C. 变频调速。把直流电变成变频交流电以驱动天调
- D. 多频放大器。同时放大具有不同频率的多个信号

正确答案：A

</details>

**题解**

**1. 相关知识点解释**
混频器（Mixer）是无线电系统中的核心器件，其核心功能是通过**非线性电路特性**将两个输入信号（如射频信号和本振信号）进行**频谱搬移**，输出信号的频率为两信号频率的和频或差频。这一过程是超外差接收机和发射机实现频率转换的关键步骤。

**2. 解题思路与分析过程**
- **选项1（频率变换）**：符合混频器的核心功能。在接收机中，混频器将接收到的射频信号与本地振荡器（LO）信号相乘，生成固定的中频信号（IF）；在发射机中则可能用于将基带信号调制到射频频率。  
- **选项2（混合式调音）**：混淆了混频器与音频混合器的功能。音频混合器负责信号叠加，而混频器不涉及扬声器输出或音频混合。  
- **选项3（变频调速）**：属于电机控制领域术语，与射频电路无关。  
- **选项4（多频放大器）**：混频器不负责放大功能，且其输出通常需要滤波器选择目标频率，而非同时处理多频信号。

**3. 答案选择原因**
混频器的本质是**频率变换**，其数学表达为：  
$$ f_{\text{out}} = |f_{\text{RF}} \pm f_{\text{LO}}| $$  
通过非线性元件（如二极管或场效应管）实现信号的乘积运算，从而产生新的频率分量。这一过程是无线通信系统实现频谱搬移的基础，与选项1的描述完全一致。

**4. 知识库引用**
知识库中《ITU 无线电规则》及《中华人民共和国无线电频率划分规定》虽未直接定义混频器，但提及的“频率容限”“必要带宽”等概念间接说明信号处理中频率转换的重要性（如超外差接收机设计需通过混频器实现频谱搬移）。  

**答案：频率变换。将信号的原始频率变换成另一个频率**

<span data-tts-skip><em>MC1-0839 · 单选 · 适用 A/B/C 类</em></span>

在超外差式收发信机中，混频器的工作方式可分为“上变频”和“下变频”两种，具体指：

:::tip 正确答案
**中频频率高于输入频率的为上变频方式，中频频率低于输入频率的为下变频方式**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 中频频率高于输入频率的为上变频方式，中频频率低于输入频率的为下变频方式 ✓
- B. 输入频率高于中频频率的为上变频方式，输入频率低于中频频率的为下变频方式
- C. 本振频率高于输入频率的为上变频方式，本振频率低于输入频率的为下变频方式
- D. 输入频率高于本振频率的为上变频方式，输入频率低于本振频率的为下变频方式

正确答案：A

</details>

**题解**

**1. 相关知识点解释**
超外差式收发信机的核心是**混频器**，其作用是将输入信号与本振信号混合，产生**中频信号（IF）**。  
- **上变频**：将输入信号转换为**更高频率**的中频信号（如发射机中将音频信号搬移到射频段）。  
- **下变频**：将输入信号转换为**更低频率**的中频信号（如接收机中将射频信号搬移到低频段以便放大和处理）。  
- **关键公式**：中频频率 $ f_{\text{IF}} = |f_{\text{LO}} - f_{\text{RF}}| $，其中 $ f_{\text{LO}} $ 为本振频率，$ f_{\text{RF}} $ 为输入射频信号频率。

**2. 解题思路与分析过程**
题目要求判断混频器的“上变频”和“下变频”定义。需明确以下逻辑：  
1. **上变频**：中频频率高于输入信号频率（$ f_{\text{IF}} > f_{\text{RF}} $）。  
2. **下变频**：中频频率低于输入信号频率（$ f_{\text{IF}} < f_{\text{RF}} $）。  
3. 题干中的其他选项（如本振频率高低）是干扰项，混频器工作方式的定义应直接基于**中频与输入频率**的关系，而非本振与输入的关系。  

**3. 答案分析**
**正确答案**：  
> **中频频率高于输入频率的为上变频方式，中频频率低于输入频率的为下变频方式**  

**选项逐一分析**：  
1. **正确**：直接基于中频与输入频率的关系，符合上变频和下变频的定义。  
2. **错误**：将“输入频率高于中频”误判为上变频（实际应为下变频）。  
3. **错误**：以本振频率为判断依据，混淆了混频器的核心功能（中频生成）。  
4. **错误**：同样以输入与本振的关系作为标准，忽略了中频的直接作用。  

**4. 结论**
混频器的工作方式应直接基于**中频与输入信号频率**的比较。上变频用于提升信号频率（如发射机），下变频用于降低信号频率（如接收机）。其他选项的判断依据（如本振频率）属于干扰项，需避免混淆。

**题解**

以下内容由AI生成（OpenAI），仅供参考。

下面给出本题的详细题解：  

**题目分析**
题干涉及 **超外差式业余收发信机（superheterodyne transceiver）** 的中频滤波器（IF Filter）。  
在超外差接收机中，信号通过本振变频后被移到一个中频频率，再由中频滤波器（例如窄带滤波器或可选的带宽控制滤波器）来选择所需的信号带宽，并抑制不需要的相邻信号或干扰。  

关键考点：
- **中频滤波器的作用**：抑制与所需信号频率接近、可能落入中频通道的干扰，即所谓的邻频或带外信号。  
- **中频滤波器不负责处理的干扰**：镜像干扰（在变频前应通过前端滤波抑制）、“中频频率干扰”（常指本机假信号干扰，也应通过前端和电路设计避免）、以及瞬态脉冲干扰（属于强度冲击干扰，应靠其他电路如噪声抑制器解决）。  

因此，本题的核心就是理解中频滤波器 **主要抑制的是邻近频率干扰**。  

**逐项分析**

**选项：“邻近频率干扰”**
- **解释**：邻近频率干扰（Adjacent channel interference）是指接收机工作频率附近的相邻信道或邻近信号进入中频通道，造成干扰。  
- 中频滤波器最关键的功能就是通过设定合适的带宽，只允许目标信号通过，并阻挡与目标信号相距很近的其他信号。  
- **结论**：这是正确答案。

**选项：“镜像频率干扰”**
- **解释**：镜像干扰（Image frequency interference）是由超外差接收机的变频原理导致的，即：当接收信号频率为 \(f_s\)，本振频率为 \(f_{LO}\)，中频为 \(f_{IF}\)，则除了 \(f_s\) 外，另一个距离本振两倍中频的频率 \(f_{im} = f_{LO} \pm f_{IF}\) 也会被变换到同样的中频，从而形成“镜像干扰”。  
- 镜像干扰的抑制是通过 **前端射频滤波器（RF Filter）** 或者 **高一中频（High-IF）设计** 来实现的，而不是通过中频滤波器。  
- **结论**：错误。

**选项：“中频频率干扰”**
- **解释**：中频干扰（IF interference）通常是指接收机工作时受到强烈信号使中频电路自激，或者外部信号正好在接收机的中频点，使接收机误认为有信号。这种干扰要靠接收机的电路设计或频率规划来避免。  
- 中频滤波器本身是在“中频级”使用的，它对目标中频信号进行处理，但对“中频频率本身引入的假信号”无能为力。  
- **结论**：错误。

**选项：“突发脉冲干扰”**
- **解释**：突发脉冲干扰常来源于点火器、开关电火花、电动机刷火、雷击等。此类干扰表现为宽频谱冲击，并非窄带邻频信号。  
- 抑制手段一般包括峰值限制、噪声抑制电路（Noise Blanker）、数字信号处理，而不是依靠中频滤波器。  
- **结论**：错误。

**正确答案**
- **邻近频率干扰**

**解题思路总结**
1. 熟悉超外差接收机的结构：  
   - 前端射频级 → 混频器 → 中频级（IF Filter） → 检波  
2. 明确中频滤波器的作用：通过带宽限制，选择目标信号，排除邻近频道。  
3. 区分典型干扰类型：  
   - **邻近频率干扰** → 中频滤波器抑制  
   - **镜像干扰** → 前端RF滤波抑制  
   - **中频干扰（假信号）** → 电路设计避免  
   - **突发脉冲干扰** → 噪声抑制电路处理  

✅ 本题的正确答案是：**邻近频率干扰**

**1. 相关知识点解释**
**超外差接收机结构**：  
超外差接收机的核心是通过混频器（Mixer）将输入信号与本振信号（Local Oscillator）混频，生成固定的中频信号（Intermediate Frequency, IF）。此时会引入一个**镜像频率干扰**（Image Frequency），其数学表达为：  
$$
f_{\text{image}} = f_{\text{LO}} + (f_{\text{LO}} - f_{\text{IF}}) = 2f_{\text{LO}} - f_{\text{IF}}
$$  
镜像频率干扰会与目标信号同时进入混频器，导致干扰无法通过中频滤波器消除，因此需要在信号进入混频器前进行抑制。

**2. 解题思路与分析过程**
- **选项1：变频级之前的波段预选滤波器**  
  波段预选滤波器位于混频器前，负责限制输入信号的频率范围。其作用是滤除带外干扰（包括镜像频率），确保只有目标频段的信号进入混频器。由于镜像频率干扰在混频前已被抑制，这是抑制镜像干扰的关键部件。

- **选项2：变频级之后的中频滤波器**  
  中频滤波器用于选择中频信号（如455kHz或10.7MHz），但镜像频率干扰在混频后会与目标信号具有相同的中频，因此中频滤波器无法区分两者，无法抑制镜像干扰。

- **选项3：中频放大级中的限幅电路**  
  限幅电路用于消除信号幅度波动（如FM解调中的噪声），与频率选择无关，对镜像干扰无抑制作用。

- **选项4：带有音调控制的音频输出电路**  
  音频输出电路处理的是解调后的音频信号，而镜像干扰在中频阶段已产生影响，此部分无法解决镜像干扰问题。

**3. 答案分析**
**正确答案：变频级之前的波段预选滤波器**  
- **原因**：  
  镜像频率干扰的产生机制决定了其必须在混频前被抑制。波段预选滤波器通过高选择性设计，在信号进入混频器前滤除镜像频率，从而避免其与本振信号混频生成干扰中频信号。  
- **其他选项排除**：  
  中频滤波器对镜像干扰无效（因两者中频相同）；限幅电路和音频电路与频率抑制无关。

**4. 知识库引用**
- 根据《No-Nonsense Technician Class License Study Guide》中关于超外差接收机和混频器的描述，镜像频率抑制依赖接收机前端滤波设计。  
- 超外差接收机的经典设计中（如ITU-R相关文献提及的接收机结构），波段预选滤波器是抑制镜像干扰的关键部件。

## 第 540 题

<span data-tts-skip><em>MC1-0843 · 单选 · 适用 A/B/C 类</em></span>

超外差式收信机所收信号的频率要比本振频率低（或高）一个中频。然而，比本振频率高（或低）一个中频的另一个遥相对应的信号也可能经混频窜入中频通道，形成“镜像频率干扰”或“镜频干扰”。如果某对讲机的技术规格书给出 NFM 方式时的第一中频为 47.25MHz，那么在 145.00MHz 收到的镜频干扰可能来自：

:::tip 正确答案
**239.50MHz 或 50.50MHz**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 239.50MHz 或 50.50MHz ✓
- B. 192.25MHz 或 97.75MHz
- C. 50.50MHz 或 101.00MHz
- D. 151.50MHz 或.202.00MHz

正确答案：A

</details>

**题解**

**1. 相关知识点解释**
镜像频率干扰（Image Frequency Interference）是超外差接收机中特有的现象。接收机通过混频器将输入信号与本振信号混合，生成中频（IF）信号。若输入信号频率为 $ f_{\text{sig}} $、本振频率为 $ f_{\text{LO}} $、中频为 $ f_{\text{IF}} $，则存在两种关系：  
- **高边注入**：$ f_{\text{LO}} = f_{\text{sig}} + f_{\text{IF}} $  
- **低边注入**：$ f_{\text{LO}} = f_{\text{sig}} - f_{\text{IF}} $  

此时，另一个与本振相差 $ f_{\text{IF}} $ 的频率（镜像频率）也会被混频到中频通道，形成干扰。**镜像频率的计算公式为**：  
$$
f_{\text{image}} = f_{\text{sig}} \pm 2f_{\text{IF}}
$$

**2. 解题思路与分析过程**
- **已知条件**：  
  - 接收信号频率 $ f_{\text{sig}} = 145.00\,\text{MHz} $  
  - 第一中频 $ f_{\text{IF}} = 47.25\,\text{MHz} $  

- **镜像频率计算**：  
  代入公式 $ f_{\text{image}} = f_{\text{sig}} \pm 2f_{\text{IF}} $：  
  $$
  f_{\text{image}} = 145.00 \pm 2 \times 47.25 = 145.00 \pm 94.5
  $$  
  得到两个可能值：  
  - $ 145.00 + 94.5 = 239.50\,\text{MHz} $  
  - $ 145.00 - 94.5 = 50.50\,\text{MHz} $  

**3. 答案分析**
- **选项对比**：  
  - **239.50MHz 或 50.50MHz**（正确）  
  - 其他选项中的频率（如192.25MHz、97.75MHz）是本振频率的可能值，而非镜像频率；151.50MHz或202.00MHz不符合计算结果。

- **结论**：  
  镜像频率干扰来源于接收频率 $ f_{\text{sig}} $ 与中频 $ f_{\text{IF}} $ 的两倍差值，即 $ 239.50\,\text{MHz} $ 和 $ 50.50\,\text{MHz} $。

**4. 结论**
正确答案：**239.50MHz 或 50.50MHz**。
