<span data-tts-skip><em>MC1-0620 · 单选 · 适用 A/B/C 类</em></span>

单边带业余电台测试检查天线驻波比需要发射平稳的连续信号。文明的作法是：

:::tip 正确答案
**将电台设为 CW 方式并按下电键。或者，将电台设为 AM 或 FM 方式并按下 PTT 键（不对话筒说话）以产生连续载波。测试结束后设回 SSB 方式**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 将电台设为 CW 方式并按下电键。或者，将电台设为 AM 或 FM 方式并按下 PTT 键（不对话筒说话）以产生连续载波。测试结束后设回 SSB 方式 ✓
- B. 将电台设为 SSB 方式，用平稳的气流对话筒吹口哨
- C. 将电台设为 SSB 方式，深呼吸后用平稳的气流对话筒发长音“啊”
- D. 将电台设为 SSB 方式，深呼吸后用平稳的气流对话筒发长音“嘻”

正确答案：A

</details>

**题解**

**1. **知识点解释****
- **驻波比（SWR）测试**：用于评估天线与发射机之间的阻抗匹配程度，需发射**稳定且无调制的连续载波**。  
- **发射方式特性**：  
  - **CW（连续波）**：通过电键控制发射等幅波，信号稳定且无调制，适合SWR测试。  
  - **AM/FM方式**：按下PTT键但不调制（如不说话）时，可产生未调制的连续载波，符合测试要求。  
  - **SSB（单边带）**：需语音调制才能输出信号，且信号强度随语音波动，不适合测试。  

**2. **解题思路****
- **测试要求**：需**平稳连续信号**，排除所有依赖语音或气流的选项（选项2-4）。  
- **选项分析**：  
  - **第一选项**：CW方式（等幅波）或AM/FM未调制载波均能提供稳定信号，符合文明操作规范。  
  - **其余选项**：SSB方式需语音调制，气流或发声的稳定性无法保证，会导致测试误差。  

**3. **答案分析****
- **正确答案**：  
  **将电台设为 CW 方式并按下电键。或者，将电台设为 AM 或 FM 方式并按下 PTT 键（不对话筒说话）以产生连续载波。测试结束后设回 SSB 方式**  
  - **理由**：  
    - CW方式通过电键直接控制发射机，产生稳定的等幅波（如A1A调制类型）。  
    - AM/FM方式在无调制时仅输出载波（如A3E或F3E未调制状态），信号平稳。  
    - SSB方式依赖语音调制，即使吹口哨或发长音“啊”/“嘻”，气流和声带振动的波动性会导致信号不稳定，无法满足测试要求。  

- **错误选项**：  
  - **SSB方式吹口哨/发长音**：语音调制信号会引入低频波动（如$ f_{\text{audio}} $），导致载波幅度变化，无法准确测量SWR。      

综上，**第一选项**是唯一符合技术要求和操作规范的文明做法。

## 第 443 题

<span data-tts-skip><em>MC1-0622 · 单选 · 适用 A/B/C 类</em></span>

使用射频/中频增益和音频增益分开控制的通信接收机进行收听时，可以这样设置：

:::tip 正确答案
**信号特弱时尽量把射频/中频增益开到最大，信号特强时尽量把音频增益开到最大，然后从低到高调整另一个增益以得到适当的音量**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 信号特弱时尽量把射频/中频增益开到最大，信号特强时尽量把音频增益开到最大，然后从低到高调整另一个增益以得到适当的音量 ✓
- B. 信号特弱时尽量把音频增益开到最大，信号特强时尽量把射频/中频增益开到最大，然后从低到高调整另一个增益以得到适当的音量
- C. 任何情况下都应将射频/中频增益放在中间位置，然后从低到高调整音频增益以得到适当的音量
- D. 任何情况下都应将音频增益放在中间位置，然后从低到高调整射频/中频增益以得到适当的音量

正确答案：A

</details>

**题解**

**1. 相关知识点解释**
通信接收机的增益控制通常分为**射频/中频增益（RF/IF Gain）**和**音频增益（Audio Gain）**：
- **射频/中频增益**：控制接收机前端对微弱信号的放大能力，直接影响信号的捕捉灵敏度。
- **音频增益**：控制音频输出的音量，仅影响解调后的音频信号强度。

**增益分配原则**：
- 对**弱信号**：应优先最大化射频/中频增益，以提升信号的接收能力，避免音频增益不足导致的信噪比恶化。
- 对**强信号**：需限制射频/中频增益，防止接收机过载或失真，通过调节音频增益控制音量。

**2. 解题思路和分析过程**
1. **选项分析**：
   - **选项一**：信号特弱时开大射频/中频增益，信号特强时开大音频增益，再调整另一增益。符合弱信号优先前端放大、强信号避免过载的原则。
   - **选项二**：弱信号开大音频增益，但音频增益对信号捕捉无直接帮助，可能导致弱信号无法被有效接收。
   - **选项三**和**选项四**：固定增益位置（如中间位置）缺乏灵活性，无法适应不同信号强度的需求。

2. **关键矛盾点**：
   - 弱信号需要**射频/中频增益最大化**，强信号需**限制射频/中频增益**，音频增益仅用于调节音量。
   - 固定增益位置或错误分配增益会降低接收效果（如噪声过大或信号失真）。

**3. 答案分析**
**正确答案**：  
**信号特弱时尽量把射频/中频增益开到最大，信号特强时尽量把音频增益开到最大，然后从低到高调整另一个增益以得到适当的音量**

- **原因**：
  - 弱信号需要通过最大化射频/中频增益提升接收灵敏度，再通过音频增益调节音量。
  - 强信号易导致接收机过载，此时需限制射频/中频增益，通过音频增益控制音量，避免失真。
  - 其他选项均未正确区分射频/中频与音频增益的功能分工，或强行固定增益位置，不符合实际操作逻辑。

**4. 补充说明**
- **过载失真**：若强信号时射频/中频增益过高，会导致接收机前端放大器饱和，产生失真。
- **动态范围管理**：合理分配增益可优化接收机动态范围，兼顾弱信号捕捉与强信号处理。

## 第 445 题

<span data-tts-skip><em>MC1-0624 · 单选 · 适用 A/B/C 类</em></span>

下面哪种方法可以减小话筒或耳机用音频电缆可能感生的射频电流？

:::tip 正确答案
**在电缆外面穿套铁氧体磁环**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 在电缆外面穿套铁氧体磁环 ✓
- B. 在电缆芯线中串联低通滤波器
- C. 在电缆前端添置话筒放大器
- D. 在电缆芯线中串联带通滤波器

正确答案：A

</details>

**题解**

**1. 相关知识点解释**
- **射频干扰（RFI）**：射频电流可能通过电磁感应或传导耦合进入音频电缆，导致噪声或设备性能下降。
- **铁氧体磁环**：铁氧体材料具有高频高阻特性，可抑制电缆上的高频共模电流，常用于电磁兼容（EMC）设计。
- **低通滤波器**：允许低频信号通过，衰减高频信号，但需注意其安装位置和阻抗匹配对音频信号的影响。
- **带通滤波器**：仅允许特定频段信号通过，可能无法覆盖所有潜在射频干扰频率。
- **话筒放大器**：主要功能是信号放大，不直接抑制干扰。

**2. 解题思路和分析过程**
1. **干扰抑制目标**：减小电缆中感生的射频电流，需从**传导路径**和**辐射耦合**两方面入手。
2. **选项分析**：
   - **铁氧体磁环**：通过增加高频阻抗抑制共模电流，直接有效（高频下铁氧体等效为电阻性负载）。
   - **低通滤波器**：若串联在芯线中，理论上可衰减高频干扰，但实际应用可能引入音频信号失真风险。
   - **话筒放大器**：无抑制射频干扰功能，可能放大噪声。
   - **带通滤波器**：仅限制频段，若射频干扰频率在带内则无效。

**3. 答案选择依据**
- **铁氧体磁环**：高频下铁氧体的阻抗特性可表示为 $ Z = R + jX $，其中电阻分量 $ R $ 在射频段显著增大，将干扰能量转化为热能。这是最直接且无源的解决方案。
- **低通滤波器**：虽然理论上可行，但实际应用中需考虑音频信号完整性（如截止频率需远高于20 kHz），且可能增加电路复杂度。
- **其他选项**：话筒放大器和带通滤波器与干扰抑制无直接关联。

**4. 最终答案**
**在电缆外面穿套铁氧体磁环**  
此方法通过物理手段直接抑制电缆上的高频共模电流，且无需改变原有电路结构，是业余无线电中最常见、最有效的解决方案。其他选项或引入额外风险（如低通滤波器），或与干扰抑制无关（如话筒放大器、带通滤波器）。

## 第 446 题

<span data-tts-skip><em>MC1-0649 · 单选 · 适用 A/B/C 类</em></span>

发射天线的作用是：

:::tip 正确答案
**把发射机输出的射频信号转化为无线电波**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 把发射机输出的射频信号转化为无线电波 ✓
- B. 利用天线的增益放大发射机的输出功率
- C. 将发射机输出的射频信号转化为音频信号
- D. 将发射机输出的射频信号转化为红外线

正确答案：A

</details>

**题解**

**1. 相关知识点解释**
发射天线是无线电通信系统中的关键组件，其核心作用是将发射机输出的射频（RF）信号转化为电磁波（无线电波），并通过辐射将能量传递到空间中。天线的增益是指其在特定方向上集中能量的能力，但增益本身并不放大功率（天线是无源器件），而是通过方向性优化信号分布。其他选项涉及的音频信号转换、红外线转换均属于不同频段或功能模块的任务，与发射天线的直接作用无关。

**2. 解题思路和分析过程**
- **选项1**：把发射机输出的射频信号转化为无线电波  
  这是发射天线的核心功能。射频信号通过天线导体产生交变电磁场，最终辐射为无线电波。
  
- **选项2**：利用天线的增益放大发射机的输出功率  
  天线增益仅优化能量方向性，不增加总功率。增益的提升是通过减少非目标方向的能量分布实现的，而非功率放大。

- **选项3**：将射频信号转化为音频信号  
  音频信号属于基带信号，射频到音频的转换需通过接收机的解调过程完成，与发射天线无关。

- **选项4**：将射频信号转化为红外线  
  红外线属于光频范围（约THz级），与射频（kHz至GHz）存在数量级差异，需完全不同的辐射机制（如LED或激光器），天线无法实现此类转换。

**3. 答案分析**
**正确答案**：把发射机输出的射频信号转化为无线电波  
该选项直接对应发射天线的核心功能。其他选项均混淆了天线与其他电路模块（如放大器、解调器）的功能，或误用物理概念（如增益=放大功率）。

**4. 参考资料**
文档：《No-Nonsense Technician Class License Study Guide》  
章节：关于天线的作用  
引用内容：发射天线通过辐射将射频信号转化为电磁波，是无线通信的基础实现方式。

## 第 447 题

<span data-tts-skip><em>MC1-0650 · 单选 · 适用 A/B/C 类</em></span>

接收天线的作用是：

:::tip 正确答案
**把空间的无线电波转化为接收机中的射频电信号**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 把空间的无线电波转化为接收机中的射频电信号 ✓
- B. 利用天线的增益放大空间的无线电波并将之传向接收机
- C. 将空间的无线电波转化为接收机中的音频信号
- D. 将空间的无线电波转化为红外线

正确答案：A

</details>

**题解**

**1. 相关知识点解释**
接收天线的核心功能是**将空间中的无线电波（电磁波）转换为接收机可处理的射频电信号**。其本质是一个能量转换器，负责捕捉电磁波并转化为高频交变电流（射频信号）。  
- **天线增益**：指天线在特定方向上集中能量的能力（方向性增强），而非直接放大信号强度。  
- **信号处理流程**：天线接收的射频信号需经过接收机的放大、解调等步骤才能转化为音频信号。  

**2. 解题思路与分析过程**
逐一分析选项：  
1. **“把空间的无线电波转化为接收机中的射频电信号”**  
   - 符合天线的基本功能，正确。  
2. **“利用天线的增益放大空间的无线电波并将之传向接收机”**  
   - 错误。增益是方向性增强，非直接放大电磁波；天线本身无放大功能，需依赖外部电路（如低噪声放大器）。  
3. **“将空间的无线电波转化为接收机中的音频信号”**  
   - 错误。音频信号是接收机对射频信号解调后的产物，与天线无关。  
4. **“将空间的无线电波转化为红外线”**  
   - 错误。红外线属于光波范畴，与无线电波性质不同，天线无法实现跨波段转换。  

**3. 答案分析**

天线增益（Antenna Gain）是天线领域的一个基本概念，指的是天线在某一特定方向上的辐射能力相对于**参考天线（通常是各向同性天线或半波振子）**的增强程度。  

天线本身不可能“无中生有”地产生额外功率，所谓“增益”并不是产生了更多的能量，而是因为天线通过**方向性（定向性）**的作用，把输入的功率在空间中的分布进行了重新分配，使得在某些方向的辐射比全向分布时更强。  

天线增益的**标准定义**是：  
\[
G(\theta, \phi) = \frac{S_{\text{antenna}}(\theta, \phi)}{S_{\text{ref}}(\theta, \phi)}
\]
其中：
- \(S_{\text{antenna}}(\theta, \phi)\)：被测天线在某方向的远场辐射功率密度  
- \(S_{\text{ref}}(\theta, \phi)\)：参考天线在相同条件下同一方向的远场辐射功率密度
