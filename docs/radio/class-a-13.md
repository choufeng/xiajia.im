<span data-tts-skip><em>MC3-0133 · 多选 · 适用 A/B/C 类</em></span>

以下哪些使用业余无线电台的行为超越了在业余业务频率范围内收发信号的规定：

:::tip 正确答案
**利用业余无线电台收听民用航空器电台通联**<span data-tts-skip>（A）</span> · **利用业余无线电台收听铁路机车电台通联**<span data-tts-skip>（B）</span> · **利用业余无线电台收听渔船海事电台通联**<span data-tts-skip>（C）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 利用业余无线电台收听民用航空器电台通联 ✓
- B. 利用业余无线电台收听铁路机车电台通联 ✓
- C. 利用业余无线电台收听渔船海事电台通联 ✓

无意接收到相关信息时也不得传播或公布。

:::tip 正确答案
**相关企业批量生产的未取得型号核准证的无线电发射设备**<span data-tts-skip>（A）</span> · **已取得型号核准证，但型号核准证载明的频率范围不含业余业务的无线电发射设备**<span data-tts-skip>（B）</span> · **已取得型号核准证，但自行更换设备操作软件将频率范围扩展到业余业务频段的无线电发射设备**<span data-tts-skip>（C）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 相关企业批量生产的未取得型号核准证的无线电发射设备 ✓
- B. 已取得型号核准证，但型号核准证载明的频率范围不含业余业务的无线电发射设备 ✓
- C. 已取得型号核准证，但自行更换设备操作软件将频率范围扩展到业余业务频段的无线电发射设备 ✓
- D. 依法改装的取得型号核准证载明的频率范围包含业余业务频段的无线电发射设备

正确答案：A、B、C

</details>

**题解**

**不可按自制、改装、拼装设备设台的情形**

- 企业批量生产但未取得型号核准的发射设备；
- 虽有型号核准，但核准频率范围不含业余业务频段的设备；
- 通过更换操作软件，把量产设备频率扩展到业余业务频段的设备。

“自制、改装、拼装”不能用于规避量产设备的型号核准要求。
