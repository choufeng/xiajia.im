## 第 171 题

<span data-tts-skip><em>MC1-0177 · 单选 · 适用 A/B/C 类</em></span>

在频率划分表中，当一个频段划分给业余业务或卫星业余业务和多个其他业务，并且业余业务和卫星业余业务作为次要业务时，业余无线电台遵循的规则是：

:::tip 正确答案
**不得对来自主要业务电台的有害干扰提出保护要求**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 不得对来自主要业务电台的有害干扰提出保护要求 ✓
- B. 可要求保护不受来自主要业务电台的有害干扰
- C. 不得对来自同一业务或其他次要业务电台的有害干扰提出保护要求
- D. 容许因设备技术问题对主要业务电台产生短时间有害干扰

正确答案：A

</details>

**题解**

**次要业务的三条规则**

- 不得对主要业务电台产生有害干扰；
- 不得要求保护其免受主要业务电台的有害干扰；
- 可以要求保护其免受同一业务或其他次要业务电台的有害干扰。

记忆：**让主要业务；同级次要业务之间仍有保护。**

:::tip 正确答案

:::

<details>
<summary>查看全部选项</summary>

- A. 7.0-7.2MHz、7.0-7.3MHz、7.0-7.2MHz，专用 ✓
