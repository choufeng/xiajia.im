<span data-tts-skip><em>MC1-0207 · 单选 · 适用 A/B/C 类</em></span>

分配给业余业务的某频段的频率下限为 F1，业余电台实际可以工作的发信频率应为：

:::tip 正确答案
**F1+信号下边带的频率宽度**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. F1+信号下边带的频率宽度 ✓
- B. F1
- C. F1-信号下边带的频率宽度
- D. F1-2×信号下边带的频率宽度

正确答案：A

</details>

**题解**

**频段下限的保护**

设频段下限为 $F_1$，若发射信号相对标称发信频率向下延伸的宽度为 $\Delta f_{下}$，则应满足：

$$
f_{发信}\ge F_1+\Delta f_{下}
$$

也就是把整个已调信号都留在频段内。LSB 频谱主要位于载频下方，因此在靠近下限时尤其要为下边带预留宽度。

:::tip 正确答案
**无需取得无线电频率使用许可**<span data-tts-skip>（A）</span> · **免收无线电频率占用费**<span data-tts-skip>（B）</span>
:::

<details>
<summary>查看全部选项</summary>

- B. 免收无线电频率占用费 ✓

- D. 需收取无线电频率占用费

正确答案：A、B

</details>

**题解**

**业余业务频率使用原则**
