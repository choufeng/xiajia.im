**相关技术原理**
6米波段是指频率在50MHz左右的甚高频（VHF）波段，波长约为6米，因此俗称"6米业余波段"。在无线电频率分配中，不同业务在同一频段可能有不同的使用状态：
- **主要业务**：在该频段享有优先使用权，其他业务不得对其造成有害干扰
- **次要业务**：必须接受主要业务的有害干扰，且不得对主要业务造成有害干扰
- **专用**：该频段专门分配给特定业务使用

   - 472–479 kHz：这是中频段（MF）的 **630 米波段**，也分配给了业余业务和卫星业余业务，但它落在 300~3000 kHz 范围内，因此属于 **中频 MF**，不是本题所问的 LF 范围。  
   - 其他选项如 137.8–138.6 kHz、134.7–135.8 kHz，并不是国际和中国对业余正式规定的频段。

   - 因此，该选项 **正确**。

2. **“137.8-138.6kHz”**  
   - 这一频率段与卫星导航、气象、航天业务密切相关，并未分配给业余业务。
