## 第 42 题

<span data-tts-skip><em>MC1-0042 · 单选 · 适用 A/B/C 类</em></span>

变更业余无线电台执照载明事项的，应当办理下列手续：

:::tip 正确答案
**及时向作出许可决定的无线电管理机构申请办理变更手续**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 及时向作出许可决定的无线电管理机构申请办理变更手续 ✓
- B. 等执照有效期届满时向核发执照的无线电管理机构申请办理变更手续，换发业余无线电台执照
- C. 只要设备型号和产品序列号没有改变，不必申请办理变更手续
- D. 只需向核发执照的无线电管理机构进行备案

正确答案：A

</details>

**题解**

**解题要点**

业余无线电台执照载明事项发生变更时，应当**及时向原作出许可决定的无线电管理机构申请办理变更手续**，不能等执照到期再处理，也不能只作备案。

即使设备型号和产品序列号未变，只要其他执照载明事项发生变化，仍应办理相应变更。

关于业余中继台的说法下列错误的是：

:::tip 正确答案
**通过发射信标信号，辅助验证电波传播条件的单发业余无线电台**<span data-tts-skip>（B）</span> · **通过对业余无线电信号接收和衰减转发，缩小通联范围的业余无线电台**<span data-tts-skip>（C）</span> · **通过接收信标信号，辅助验证电波传播条件的单发业余无线电台**<span data-tts-skip>（D）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 通过对业余无线电信号接收和放大转发，扩大通联范围的业余无线电台
- B. 通过发射信标信号，辅助验证电波传播条件的单发业余无线电台 ✓
- C. 通过对业余无线电信号接收和衰减转发，缩小通联范围的业余无线电台 ✓
- D. 通过接收信标信号，辅助验证电波传播条件的单发业余无线电台 ✓

</details>

**题解**

**术语辨析**

- **业余中继台**：接收并放大转发业余无线电信号，用于扩大通联范围；
- **业余信标台**：主动发射信标信号，用于辅助验证电波传播条件。

因此，“接收信标信号的单发信标台”或“衰减转发并缩小通联范围的中继台”等说法都不符合定义。

可以组织 A 类和 B 类业余无线电台操作技术能力验证的机构是：

:::tip 正确答案
**国家无线电管理机构和省、自治区、直辖市无线电管理机构**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>
