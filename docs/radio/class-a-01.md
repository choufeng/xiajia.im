## 第 1 题

<span data-tts-skip><em>MC2-0001 · 多选 · 适用 A/B/C 类</em></span>

我国专门针对无线电管理的行政法规及其制定机构是：

:::tip 正确答案
**《中华人民共和国无线电管理条例》**<span data-tts-skip>（A）</span> · **国务院和中央军委**<span data-tts-skip>（C）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 《中华人民共和国无线电管理条例》 ✓
- B. 《中华人民共和国无线电管理办法》
- C. 国务院和中央军委 ✓
- D. 工业和信息化部

正确答案：A、C

</details>

**题解**

行政法规是《中华人民共和国无线电管理条例》，由**国务院和中央军委**联合制定。注意区分：《业余无线电台管理办法》是工业和信息化部的部门规章，不是行政法规。

在频率划分表中，一个频段被标明划分给多种业务时，这些业务被分为下述类别：

:::tip 正确答案
**主要业务和次要业务**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 主要业务和次要业务 ✓

- C. 民用业务和军用业务

辐射（radiation）是指任何源的能量流以无线电波的形式向外发出。正确的说法是：

:::tip 正确答案
**闪电产生的电磁波干扰是一种辐射**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 闪电产生的电磁波干扰是一种辐射 ✓
- B. 沿电源线窜入接收机的差模干扰是一种辐射
- C. 射频电路中变压器内磁芯里的磁场是一种辐射
- D. 射频电路中电容器内极板间的电场是一种辐射

</details>

**题解**

**解题要点**

记忆关键词：**辐射 → 闪电**。
