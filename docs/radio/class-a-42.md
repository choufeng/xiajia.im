**题解**

以下内容由AI生成（OpenAI），仅供参考。

题解开始：  

**一、题目分析**
本题考查的是**业余电台在调频（FM）方式下出现语音失真、可辨度差的常见原因**。  
在实际通信中，如果另一端报告“你的信号听起来失真严重”，说明对方接收到的音频被严重扭曲。这可能与**发射机电源、电台频率偏离、多径传播环境**等因素相关，而与天线功率承载能力无关。考生需要能根据不同情况判断**可能原因**和**处理方法**。

关键词：调频、失真、可辨度差。  

**二、选项逐一分析**

**1. **“电台的电源电压不足，可以检查供电电压或更换电池模块再试”****
- 分析：  
  便携电台或车载电台如果电池电压不足，发射机的频率合成电路、功放级、偏置电路将不能正常工作。结果可能引起：  
  - 发射频率漂移 → 接收端出现失真；  
  - 调制幅度不足或非线性 → 音质劣化。  
- 结论：这是导致对方听到失真的常见原因，选项正确。  

**2. **“电台所处的位置多径衰落严重，可以挪动几步或变更频率再试”****
- 分析：  
  FM 调制在多径条件下往往会产生“相长相消干扰”，导致接收端出现“摆动声”“断续”“失真”。在城市高楼或反射环境中尤其明显。通过**移动位置或更换频点**，能减轻多径失真。  
- 结论：该说法正确。  

**3. **“电台的发射频率不准。如确认这种情况，需修好设备之后再试”****
- 分析：  
  调频通信依赖于发射机频率与接收机频率的严格一致。如果发射机频率漂移过大（石英振荡器老化、电源电压不足、PLL 锁相不稳），接收机解调会产生明显失真，表现为声音模糊甚至可辨度极差。  
- 结论：此选项也是正确的。  

**4. **“电台天线承载射频功率的能力不足，需更换高级天线之后再试”****
- 分析：  
  天线的作用是将射频功率有效辐射出去。所谓“天线承载射频功率的能力不足”一般指**功率容量问题（长时间高功率发射导致天线发热烧毁）**，与语音失真基本无关。  
  即使天线匹配不好，也主要导致发射效率降低或驻波比升高，但不会直接导致调频语音的失真、可辨度差。  
- 结论：该选项错误。  

**三、解题思路**
1. 判断失真原因时，先考虑电台内部问题（电源、电路、频率精度）；  
2. 然后考虑传输环境问题（多径衰落）；  
3. 与天线功率承载能力无关，因此可排除。  

**四、知识点总结**
1. **电源电压不足** → 频率漂移、非线性工作 → 语音失真。  
2. **多径衰落** → 接收信号重叠干扰 → 声音失真。  
3. **发射频率不准** → 接收机无法正确解调 → 失真严重。  
4. **天线承载功率**只影响效率或安全，不影响调频语音失真判断。  

**五、最终答案**
正确选项为：  
- **电台的电源电压不足，可以检查供电电压或更换电池模块再试**  
- **电台所处的位置多径衰落严重，可以挪动几步或变更频率再试**  
- **电台的发射频率不准。如确认这种情况，需修好设备之后再试**  

错误选项为：  
- **电台天线承载射频功率的能力不足，需更换高级天线之后再试**

## 第 419 题

<span data-tts-skip><em>MC1-0598 · 单选 · 适用 A/B/C 类</em></span>

如果进行 SSB 或 CW 通联时周边环境嘈杂，哪种设备可以替代电台上的扬声器，改善话音抄收？

:::tip 正确答案
**耳机**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 耳机 ✓
- B. 低通滤波器
- C. 视频显示器
- D. 吊杆胖话筒

正确答案：A

</details>

**题解**

**1. 相关知识点解释**
SSB（单边带）和CW（连续波）通联时，接收端需要将接收到的射频信号转换为音频信号以便抄收。在嘈杂环境中，声音隔离和信号处理能力直接影响抄收效果。  
- **耳机**：通过物理隔离（如封闭式设计）或主动降噪技术（ANC）降低环境噪音，直接将清晰的音频信号传入耳中。  
- **低通滤波器**：滤除高频噪声，改善信号纯度，但属于电路信号处理设备，不替代扬声器。  
- **视频显示器**：用于数字模式（如SDR）的频谱或瀑布图显示，无法直接替代音频输出设备。  
- **吊杆话筒**：用于语音输入（发射），与接收端无关。

**2. 解题思路与分析过程**
- **目标**：寻找能替代扬声器且改善抄收的设备。  
- **排除法**：  
  - **低通滤波器**（处理信号而非替代输出设备）  
  - **视频显示器**（可视化工具，不输出音频）  
  - **吊杆话筒**（发射端设备，与接收无关）  
- **剩余选项**：**耳机**是唯一能直接替代扬声器，且通过物理隔离改善抄收的设备。

**3. 答案分析**
- **正确答案**：**耳机**  
  - **原因**：  
    - 耳机可隔绝环境噪音，避免干扰接收信号的音频输出。  
    - 封闭式设计或主动降噪技术进一步提升语音清晰度。  
    - 直接替代扬声器，符合题目需求。  
- **错误选项**：  
  - **低通滤波器**：改善信号质量但不替代扬声器。  
  - **视频显示器**：需配合音频设备使用，无法独立实现抄收。  
  - **吊杆话筒**：仅用于发射，与接收无关。

- A. NB 为“抑噪”，切除高于平均信号的大幅度突发脉冲噪声；SQL 为“静噪”，信噪比达不到一定水平时自动关闭音频输出 ✓

- C. NB 和 SQL 都是指“静噪”，切除高于平均信号的大幅度突发脉冲噪声

**题解**
