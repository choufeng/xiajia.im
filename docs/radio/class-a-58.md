接收机的静噪灵敏度是指：

:::tip 正确答案
**能够使静噪电路退出静噪状态的射频信号最小输入电平**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 能够使静噪电路退出静噪状态的射频信号最小输入电平 ✓
- B. 关闭静噪功能之后所能接收到的射频信号最小输入电平
- C. 带有静噪功能的接收机开启静噪功能后，按照灵敏度定义测得的灵敏度
- D. 带有静噪功能的接收机关闭静噪功能后，按照灵敏度定义测得的灵敏度

正确答案：A

</details>

**题解**

**1. 知识点解释**
**静噪灵敏度**是接收机的一项重要性能指标，用于描述静噪电路能够响应并退出静噪状态的最小射频信号强度。静噪功能的作用是在无信号或信号微弱时关闭音频输出，以抑制背景噪声；当接收到的信号强度超过设定门限时，静噪电路解除静默状态，允许信号通过。因此，静噪灵敏度直接反映了接收机对弱信号的检测能力。

**2. 解题思路**
题目要求判断“接收机的静噪灵敏度”的正确定义，需明确以下逻辑：  
- **静噪灵敏度的核心**是“触发静噪电路退出静噪状态的最小信号强度”。  
- 静噪功能是否开启直接影响灵敏度的测量条件：  
  - 若静噪功能关闭，则灵敏度测试与普通接收机一致（对应常规灵敏度）。  
  - 若静噪功能开启，则需测量静噪电路被激活时的信号门限。  

结合选项分析：  
1. **“能够使静噪电路退出静噪状态的射频信号最小输入电平”**  
   - 直接对应静噪灵敏度的定义，即触发静噪解除的最低信号强度。  
2. **“关闭静噪功能之后所能接收到的射频信号最小输入电平”**  
   - 描述的是普通灵敏度，与静噪功能无关。  
3. **“开启静噪功能后，按照灵敏度定义测得的灵敏度”**  
   - 混淆了静噪灵敏度与普通灵敏度的测试条件。  
4. **“关闭静噪功能后，按照灵敏度定义测得的灵敏度”**  
   - 同样描述普通灵敏度，而非静噪灵敏度。

**3. 答案分析**
**正确答案：**  
“能够使静噪电路退出静噪状态的射频信号最小输入电平”  

**原因：**  
- 静噪灵敏度的本质是静噪电路的触发门限，而非静噪关闭后的普通灵敏度。  
- 其他选项描述的均是静噪功能关闭或测试条件不匹配的情况，不符合定义。  

**错误选项分析：**  
- **“关闭静噪功能之后所能接收到的射频信号最小输入电平”**  
  - 此为普通灵敏度定义，与静噪功能无关。  
- **“开启静噪功能后，按照灵敏度定义测得的灵敏度”**  
  - 静噪开启时，接收机可能因信号不足处于静默状态，无法直接测量灵敏度。  
- **“关闭静噪功能后，按照灵敏度定义测得的灵敏度”**  
  - 同上，静噪关闭后的灵敏度测试与常规接收机一致，与静噪灵敏度无关。

**4. 补充说明**
- 静噪灵敏度通常以**dBm**为单位表示，反映接收机在静噪状态下对弱信号的响应能力。  
- 在实际应用中，静噪灵敏度需与接收机动态范围、噪声系数等参数结合分析，以确保系统在复杂电磁环境中的可靠性。

:::tip 正确答案

<summary>查看全部选项</summary>

- A. 接收机输入端信噪比 Si/Ni 对输出端信噪比 So/No 的比值的对数形式 ✓
- B. 接收机输入端无信号时，输出端的噪声功率电平的对数形式
- C. 接收机输出端噪声功率电平与输入端噪声功率电平的比值的对数形式
- D. 接收机输入端噪声功率电平与输出端噪声功率电平的比值的对数形式

正确答案：A

</details>

**题解**

**题解：接收机噪声指数 NF 的定义**

****1. 知识点解释****
**噪声指数（Noise Figure, NF）** 是描述接收机内部噪声对信号质量影响的指标，反映接收机前端对信噪比的恶化程度。  
- **物理意义**：NF 越低，接收机性能越好，尤其在接收微弱信号（如 EME 通联）时，低 NF 能显著提升弱信号检测能力。  
- **数学定义**：  
  $
  \text{NF} = 10 \log_{10} \left( \frac{S_i/N_i}{S_o/N_o} \right)
  $
  其中：  
  - $ S_i/N_i $：接收机输入端的信噪比（Signal-to-Noise Ratio, SNR）；  
  - $ S_o/N_o $：接收机输出端的信噪比。

****2. 解题思路****
题目要求判断 NF 的定义形式，需注意以下关键点：  
1. **核心定义**：NF 描述的是**信噪比的恶化**，而非单纯的噪声功率变化。  
2. **单位形式**：题目明确指出 NF 是“对数形式”，即以分贝（dB）表示。  
3. **排除干扰项**：  
   - 若选项仅涉及噪声功率电平的比值（如选项3、4），则不符合 NF 的定义；  
   - 若选项描述输出端噪声功率与输入端无关（如选项2），则混淆了 NF 与噪声温度（Noise Temperature）的概念。

****3. 答案分析****
**正确选项**：  
**接收机输入端信噪比 $ S_i/N_i $ 对输出端信噪比 $ S_o/N_o $ 的比值的对数形式**  

**错误选项分析**：  
1. **错误选项1**（干扰项）：  
   - **描述**：“接收机输入端无信号时，输出端的噪声功率电平的对数形式”  
   - **错误原因**：此描述对应**接收机本底噪声**（Minimum Detectable Signal, MDS），而非 NF。NF 需考虑输入信号的信噪比变化。  

2. **错误选项2**（干扰项）：  
   - **描述**：“接收机输出端噪声功率电平与输入端噪声功率电平的比值的对数形式”  
   - **错误原因**：此描述仅涉及噪声功率的传递，未包含信号成分，无法反映信噪比的恶化。  

3. **错误选项3**（干扰项）：  
   - **描述**：“接收机输入端噪声功率电平与输出端噪声功率电平的比值的对数形式”  
   - **错误原因**：方向错误（输入 vs. 输出），且未涉及信号成分。

**结论**：  
噪声指数 NF 是衡量接收机前端对信噪比恶化的核心指标，其定义为输入信噪比与输出信噪比的比值取对数形式。正确答案通过排除仅涉及噪声功率的干扰项，明确指向信噪比的对比逻辑。

## 第 574 题

<span data-tts-skip><em>MC1-0883 · 单选 · 适用 A/B/C 类</em></span>

对于需要接收微弱信号的业余通信，例如 EME 通联，接收机的噪声指数 NF（以对数表示）是一项重要技术指标。关于 NF 的一些基本常识是：

:::tip 正确答案
**NF 一定大于 0；在同样的灵敏度下，NF 越接近 0 越好**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. NF 一定大于 0；在同样的灵敏度下，NF 越接近 0 越好 ✓
- B. NF 一定小于 0；在同样的灵敏度下，NF 越接近 0 越好
- C. NF 一定大于 1；在同样的灵敏度下，NF 越大越好
- D. NF 一定处于 0 和 1 之间；在同样的灵敏度下，NF 越接近 1 越好

正确答案：A

</details>

**题解**

**1. 知识点解释**
**噪声指数（Noise Figure, NF）**：  
NF是衡量接收机内部噪声对信号质量影响的关键指标，定义为：  
$$
NF = 10 \log_{10} \left( \frac{S_{\text{in}}/N_{\text{in}}}{S_{\text{out}}/N_{\text{out}}} \right)
$$  
其中，$S_{\text{in}}/N_{\text{in}}$ 是输入信噪比，$S_{\text{out}}/N_{\text{out}}$ 是输出信噪比。  
- **物理意义**：NF表示接收机因自身噪声导致的信噪比恶化程度，单位为分贝（dB）。  
- **取值范围**：NF必须**大于0 dB**，因为任何实际接收机都会引入额外噪声（理想接收机NF=0 dB，但现实中无法实现）。  
- **性能影响**：NF越小，接收机对微弱信号的接收能力越强（即“越接近0越好”）。  

**EME通联（Earth-Moon-Earth）**：  
通过月球反射无线电波实现远距离通信，信号极其微弱，因此对接收机的低噪声性能要求极高。

**2. 解题思路与分析**
题目要求判断关于NF的表述是否正确，关键在于理解以下两点：  
1. **NF的数学定义与物理意义**：  
   - NF是噪声系数（Noise Factor, F）的对数形式：$NF = 10 \log_{10} F$。  
   - 噪声系数F是线性量（F ≥ 1），因此NF ≥ 0 dB。  
2. **性能优化目标**：  
   - 在相同灵敏度下，NF越小（即越接近0 dB），接收机噪声越低，系统性能越优。  

**选项分析**：  
1. **“NF一定大于0；在同样的灵敏度下，NF越接近0越好”**：  
   - **正确**。根据定义，NF ≥ 0 dB，且NF越小，噪声越低。  
2. **“NF一定小于0；在同样的灵敏度下，NF越接近0越好”**：  
   - **错误**。NF不能为负值（对应线性噪声系数F < 1，物理上不可实现）。  
3. **“NF一定大于1；在同样的灵敏度下，NF越大越好”**：  
   - **错误**。NF是分贝值（单位dB），而“1”是线性量（F=1对应NF=0 dB）。NF越大，噪声越高，性能越差。  
4. **“NF一定处于0和1之间；在同样的灵敏度下，NF越接近1越好”**：  
   - **错误**。混淆了线性噪声系数F（F ≥ 1）与分贝值NF（NF ≥ 0 dB）。  

**3. 答案与原因**
**正确答案**：第一个选项  
**原因**：  
- **理论依据**：根据噪声指数的定义，NF必须大于0 dB，且越接近0 dB越好（对应最小噪声）。

**4. 总结**
本题考查对噪声指数定义及物理意义的理解。关键点在于区分噪声系数（F ≥ 1）与噪声指数（NF ≥ 0 dB），并明确NF越小性能越优的工程目标。
