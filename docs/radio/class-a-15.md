:::tip 正确答案
**中华人民共和国民法典**<span data-tts-skip>（A）</span>
:::

<details>

## 第 142 题

:::tip 正确答案

## 第 144 题

<span data-tts-skip><em>MC1-0150 · 单选 · 适用 A/B/C 类</em></span>

在特定时间和特定区域内实施无线电管制时，与业余无线电有关的管理措施包括：

:::tip 正确答案
**限制或者禁止业余无线电台（站）的使用，以及对特定的无线电频率实施技术阻断等**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 限制或者禁止业余无线电台（站）的使用，以及对特定的无线电频率实施技术阻断等 ✓
- B. 限制或者禁止业余无线电台设备的生产和销售
- C. 限制、但不会禁止业余无线电台（站）的使用
- D. 依法设置的业余电台不在管制范围之内

正确答案：A

</details>

**题解**

**管制措施**

实施无线电管制时，可以限制或禁止业余无线电台（站）的使用，并对特定无线电频率实施技术阻断等措施。

无线电管制针对无线电波的发射、辐射和传播，不是对设备生产销售的一般限制。

## 第 145 题

<span data-tts-skip><em>MC2-0151 · 多选 · 适用 A/B/C 类</em></span>

决定实施无线电管制的机构为：

:::tip 正确答案
**在全国范围内或者跨省、自治区、直辖市实施，由国务院和中央军事委员会决定**<span data-tts-skip>（A）</span> · **在省、自治区、直辖市范围内实施，由省、自治区、直辖市人民政府和相关军区决定**<span data-tts-skip>（B）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 在全国范围内或者跨省、自治区、直辖市实施，由国务院和中央军事委员会决定 ✓
- B. 在省、自治区、直辖市范围内实施，由省、自治区、直辖市人民政府和相关军区决定 ✓
- C. 在全国范围内或者跨省、自治区、直辖市实施，由国家无线电管理机构决定
- D. 在省、自治区、直辖市范围内实施，由相关地方无线电管理机构决定

正确答案：A、B

</details>

**题解**

**无线电管制决定机关**

- 全国范围或跨省实施：由**国务院和中央军事委员会**决定；
- 省、自治区、直辖市范围内实施：由**省级人民政府和相关军区**决定。

记忆点：两级决定机关都包含相应军事机关。

## 第 146 题

<span data-tts-skip><em>MC2-0152 · 多选 · 适用 A/B/C 类</em></span>

违反无线电管制命令和无线电管制指令的，由下列机构依法进行处罚：

:::tip 正确答案
**国家无线电管理机构或者省、自治区、直辖市无线电管理机构**<span data-tts-skip>（A）</span> · **违反治安管理规定者由公安机关处罚**<span data-tts-skip>（B）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 国家无线电管理机构或者省、自治区、直辖市无线电管理机构 ✓
- B. 违反治安管理规定者由公安机关处罚 ✓
- C. 当地业余无线电协会
- D. 所在军区派出的专门机构

正确答案：A、B

</details>

**题解**

**处罚机关**

- 违反无线电管制命令、指令：由国家或省级无线电管理机构依法处罚；
- 同时违反治安管理规定：由公安机关处罚。

无线电协会是民间组织，不是执法机关。
