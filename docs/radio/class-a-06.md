## 第 54 题

<span data-tts-skip><em>MC3-0056 · 多选 · 适用 A/B/C 类</em></span>

国家无线电管理机构及其委托的机构可以组织实施如下类别的业余无线电台操作技术能力验证：

:::tip 正确答案
**A 类业余无线电台操作技术能力验证**<span data-tts-skip>（A）</span> · **B 类业余无线电台操作技术能力验证**<span data-tts-skip>（B）</span> · **C 类业余无线电台操作技术能力验证**<span data-tts-skip>（C）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. A 类业余无线电台操作技术能力验证 ✓
- B. B 类业余无线电台操作技术能力验证 ✓
- C. C 类业余无线电台操作技术能力验证 ✓
- D. 一级个人业余电台操作证书

正确答案：A、B、C

</details>

**题解**

**1. 知识点解释**
根据《业余无线电台管理办法》第三章 **操作技术能力验证** 的相关规定：  
- **A类、B类、C类** 是国家无线电管理机构明确划分的业余无线电台操作技术能力验证类别（依据第二十五条）。  
- **验证权限**：  
  - 国家无线电管理机构可组织实施 **A类、B类、C类** 验证（第二十七条第一款）。  
  - 省级无线电管理机构可组织实施 **A类、B类** 验证（第二十七条第二款）。  
- **一级个人业余电台操作证书** 并非法规中规定的验证类别，属于干扰项。

**2. 解题思路与分析**
题目要求判断哪些验证类别属于国家无线电管理机构及其委托机构可组织的范围。  
1. **A类、B类、C类**：直接依据法规条文第二十七条，明确由国家无线电管理机构组织实施。  
2. **一级个人业余电台操作证书**：法规中未提及此名称，属于混淆项（可能与国际GMDSS证书混淆，但与业余电台无关）。

**3. 答案分析**
- **A类业余无线电台操作技术能力验证**：正确，国家无线电管理机构可组织实施（《业余无线电台管理办法》第二十七条）。  
- **B类业余无线电台操作技术能力验证**：正确，同上。  
- **C类业余无线电台操作技术能力验证**：正确，同上。  
- **一级个人业余电台操作证书**：错误，法规中无此验证类别，可能为虚构名称。

**4. 结论**
**正确答案：A类、B类、C类业余无线电台操作技术能力验证**。  
**一级个人业余电台操作证书** 不属于国家无线电管理机构组织实施的验证类别。  

**引用文档**：  
《业余无线电台管理办法》第三章 **操作技术能力验证**（第二十五条、第二十七条）。
