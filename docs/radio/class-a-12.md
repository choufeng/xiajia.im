:::

## 第 112 题

<span data-tts-skip><em>MC1-0118 · 单选 · 适用 A/B/C 类</em></span>

具备国家无线电管理机构规定的操作技术能力并具有法律规定有效证明文件、但还没有获准设置自己的业余电台的人是否可以到业余电台进行发射操作？答案是：

:::tip 正确答案
**可以。使用所操作业余电台的呼号，由该业余电台的设台人对操作不妥而造成的有害干扰负责**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 可以。使用所操作业余电台的呼号，由该业余电台的设台人对操作不妥而造成的有害干扰负责 ✓
- B. 可以。因为自己没有呼号，只能在通信中使用临时自编的呼号，或用姓名代替呼号
- C. 不可以
- D. 青少年可以，成人不可以

正确答案：A

</details>

**题解**

**客席发射**

具备规定操作技术能力并持有有效证明、但尚未获准设置自己电台的人，可以在他人依法设置的业余无线电台上发射：

- 使用所操作业余无线电台的呼号；
- 设台人对操作不当造成的有害干扰负责。

不要套用“凡是问可不可以都选不可以”的机械技巧。

## 第 114 题

业余无线电台设置人应对其无线电发射设备担负的法定责任为：

:::tip 正确答案
**应当确保其无线电发射设备处于正常工作状态，避免对其他无线电业务造成有害干扰**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 应当确保其无线电发射设备处于正常工作状态，避免对其他无线电业务造成有害干扰 ✓
- B. 应当确保其无线电发射设备随最先进型号更新，为其他业余电台树立求新的榜样
- C. 应当确保其无线电发射设备达到最大发射功率，以克服其他无线电业务的干扰
- D. 应当确保其无线电发射设备经常处于工作状态，以提高业余频率的实际占用度

正确答案：A

</details>

**题解**

**设台人的法定责任**

业余无线电台设置人应确保无线电发射设备处于正常工作状态，避免对其他无线电业务造成有害干扰。

实际操作中还应合理使用功率、频率和必要带宽，但法定责任的核心是**设备正常、避免有害干扰**。

:::tip 正确答案
**不可以，不得发送与业余业务和卫星业余业务无关的信号**<span data-tts-skip>（A）</span>
:::
