## 第 425 题

<span data-tts-skip><em>MC1-0604 · 单选 · 适用 A/B/C 类</em></span>

既然全功能收信机具有 AGC 功能，那为什么好多机型还要装设衰减（ATT）开关？

:::tip 正确答案
**特强带外信号可以阻塞接收机的前级电路，致使器件非线性工作，产生失真和互调。此时需在接收机的前端电路之前加入衰减器，并用开关控制其切入与否**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 特强带外信号可以阻塞接收机的前级电路，致使器件非线性工作，产生失真和互调。此时需在接收机的前端电路之前加入衰减器，并用开关控制其切入与否 ✓
- B. 通常，增益控制旋钮的控制范围不够宽，加入 ATT 开关可以拓展增益控制范围
- C. 如果遭遇特强带内干扰，那么打开 ATT 就可防止过大的音量损坏扬声器或耳机了
- D. 这可以防止本台发射机的强信号损坏本台的接收机电路

正确答案：A

</details>

**题解**

**为什么有 AGC 还需要 ATT**

**AGC** 主要根据接收机中后级检测到的电平调节增益；若强烈的带外信号已经使前端放大器或混频器过载，AGC 来不及在失真产生前解决问题。

**ATT** 位于接收前端之前，先把所有输入信号衰减，能避免前级阻塞、非线性失真和互调。因此强信号环境下仍需要独立的 ATT 开关。

**题解**

**强干扰与 AGC**

微弱有用信号与强干扰同时出现时，强干扰会驱动 AGC 降低接收机增益，使微弱信号也被一起压低。此时可关闭 AGC，手动调整射频增益，在避免前端过载的前提下尝试抄收弱信号。

关闭 AGC 不是普遍的默认设置，只适用于需要人工控制增益的特定强弱信号并存场景。

- C. 将接收机应用于“比幅度法规”测向时
- D. 有用微弱信号和强干扰同时出现时

**题解**

**AGC 时间常数**

SSB 和 AM 的正常信号包络会随语音不断变化。若 AGC 响应过快，它会追随这些正常的调制起伏，造成听感不自然或增益“抽动”。

因此接收 SSB、AM 时通常选择较长、较慢的 AGC 时间常数，让 AGC 主要跟随传播衰落等较慢变化。

## 第 430 题

<span data-tts-skip><em>MC1-0609 · 单选 · 适用 A/B/C 类</em></span>

多数小型全功能收发信机的面板上都可以看到符号 PRE，其代表什么功能？

:::tip 正确答案
**收信机前置放大器，在接收微弱信号时接入（此时某些技术指标可能低于额定值）**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 收信机前置放大器，在接收微弱信号时接入（此时某些技术指标可能低于额定值） ✓
- B. 自动天线调谐，对天线电路的电压驻波比进行检测并进行自动补偿，以维持最小驻波比
- C. 发信自动电平控制，对射频输出电平进行检测并反馈控制，以维持其在适当限度之内
- D. 发信语音压缩，对音频输入电平进行检测并反馈控制，以提升语音包络幅度较小的部分

正确答案：A

</details>

**题解**

**1. 知识点解释**
**收信机前置放大器（Preamplifier）**：  
在接收微弱信号时，前置放大器通过提升信号强度来提高接收灵敏度。但由于放大噪声的同步性，可能使某些技术指标（如信噪比）低于设备标称值。其核心作用是增强信号，但需权衡噪声影响。  

**2. 解题思路**
- **选项分析**：  
  - **第一个选项**：直接描述PRE的核心功能——接收弱信号时接入前置放大器，技术指标可能降额（符合实际）。  
  - **第二个选项**：自动天线调谐（ATU）功能，与电压驻波比（VSWR）相关，但PRE与天线匹配无直接关联。  
  - **第三个选项**：发信自动电平控制（ALC）功能，用于稳定发射功率，属于发射链路而非接收链路。  
  - **第四个选项**：发信语音压缩功能，涉及音频动态范围处理，属于发射端音频信号处理。  
- **逻辑排除**：  
  PRE通常用于接收机前端，而非发射部分（排除第三、四选项）；其功能聚焦信号放大而非天线调谐（排除第二选项）。  

**3. 答案分析**
**正确答案**：**收信机前置放大器，在接收微弱信号时接入（此时某些技术指标可能低于额定值）**  
- **依据**：PRE的英文全称“Preamplifier”明确指向接收机前端的信号增强功能。  
- **技术降额原因**：前置放大器可能引入噪声（如噪声系数增加），导致接收机灵敏度等指标在启用时低于标称值。  
- **其他选项排除**：  
  - 自动天线调谐（ATU）通常标记为“TUNER”或“ANT TUNE”。  
  - 发信自动电平控制（ALC）和语音压缩均与发射信号处理相关，与“PRE”标识无关。  

**总结**：PRE功能专为接收微弱信号设计，通过前置放大提升信号强度，但需注意其对系统噪声和指标的影响。其他选项涉及发射或天线调谐，与PRE无直接关联。
