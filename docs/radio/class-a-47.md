<span data-tts-skip><em>MC1-0666 · 单选 · 适用 A/B/C 类</em></span>

:::

<details>
<summary>查看全部选项</summary>

- A. 甲天线的信号功率为乙天线的两倍 ✓
- B. 甲天线的信号功率为乙天线的 1/2
- C. 甲天线的信号功率为乙天线的 5.15 倍
- D. 甲天线的信号功率为乙天线的 6.15 倍

正确答案：A

</details>

**题解**

答案是 甲天线的信号功率为乙天线的两倍。

- 首先将乙天线增益单位换算为dBi，根据0dBd = 2.15dBi，可得乙偶极天线增益为1dBd = 1 + 2.15dBi=3.15dBi。

- 然后根据公式 $ G=10\lg\frac{P_{1}}{P_{0}} $（其中 $G$ 为增益， $P_{1}$ 为实际天线在某点产生的功率， $P_{0}$ 为参考天线在同一点产生的功率），设甲天线信号功率为 $P_{甲}$ ，乙天线信号功率为 $P_{乙}$ ，则甲、乙天线增益差 $\Delta G = 10\lg\frac{P_{甲}}{P_{乙}}$ 。

- 甲、乙天线增益差为 $\Delta G=6.15dBi - 3.15dBi = 3dBi$ ，代入公式可得 $3 = 10\lg\frac{P_{甲}}{P_{乙}}$ ，即 $\lg\frac{P_{甲}}{P_{乙}}=0.3$ ，则 $\frac{P_{甲}}{P_{乙}} = 10^{0.3}\approx2$ 。所以甲天线的信号功率约为乙天线的两倍，答案选A。

**驻波比（SWR）**

- 完美匹配时没有反射波，SWR 为 $1:1$，不会是 $0$；

- D. 天线系统的整体增益仅为 4dB

**题解**

以下内容由AI生成（OpenAI），仅供参考。

**题目解析**

题目问的是：**“通联时，如果收发信机的 SWR 表显示读数 4:1，则意味着什么？”**  
关键词：SWR（Standing Wave Ratio，驻波比），这是业余无线电考试的常考知识点。  

**1. 原理知识回顾**

- **驻波比的定义：**  
  \[
  \text{SWR} = \frac{1 + |\Gamma|}{1 - |\Gamma|}
  \]  
  其中 \(\Gamma\) 为反射系数：  
  \[
  \Gamma = \frac{Z_L - Z_0}{Z_L + Z_0}
  \]  
  - \(Z_L\)：负载（天线输入端阻抗）  
  - \(Z_0\)：系统特性阻抗（通常为 50 欧姆）

- **SWR 含义：**  
  - SWR = 1:1 表示负载与传输线完全匹配，没有反射功率。  
  - SWR > 1 表示不匹配，有反射功率。值越大，匹配越差。  
  - 当 SWR = 4:1 时：  
    \[
    |\Gamma| = \frac{\text{SWR}-1}{\text{SWR}+1} = \frac{4-1}{4+1} = \frac{3}{5} = 0.6
    \]  
    表示有 60% 的电压反射回去，反射功率比例为：  
    \[
    |\Gamma|^2 = 0.6^2 = 0.36 = 36\%
    \]  
    即有 36% 的功率被反射回发射机。

**2. 逐一分析选项**

**（1）“从发射机的输出端口来看，天线系统的整体匹配情况不佳”**  
- 正确。SWR 达到 4:1，说明天线输入阻抗与 50Ω 传输线不匹配，有较大反射功率。  
- 这正是 SWR 表读数直接反映的工程含义。

**（2）“从发射机的输出端口来看，天线系统的整体阻抗为 200 欧或 12.5 欧”**  
- 部分正确，但不够严谨。  
- 对于 50Ω 系统：  
  - SWR 的计算结果确实可能来源于 \(Z_L = 200Ω\) 或 \(Z_L = 12.5Ω\)：  
    \[
    \text{SWR} = \frac{\max(Z_L, Z_0)}{\min(Z_L, Z_0)} = \frac{200}{50} = 4，\quad \text{或 } \frac{50}{12.5} = 4
    \]  
  - 但这并不是唯一可能值。SWR = 4:1 可以对应一系列复数阻抗（不仅限于纯电阻 200Ω 或 12.5Ω）。  
  - 题目问的是“意味着”，即要求通用解释，而这个选项过于狭窄、容易误导。  

因此这个选项不正确。

**（3）“天线系统的辐射效率仅为 25%”**  
- 错误。SWR 只反映匹配程度和反射功率，不直接等于辐射效率。  
- 虽然有反射损耗，但辐射效率更多取决于天线本身的电阻损耗和地效应，而不是单从 SWR 就能确定。  
- 计算反射功率：当 SWR = 4:1，反射 36% 功率 → 仍有 64% 功率传到天线，但这并不意味着天线辐射效率 = 25%。  

因此这个选项错误。

**（4）“天线系统的整体增益仅为 4dB”**  
- 错误。SWR 不表示天线增益，二者是完全不同的概念。  
- 天线增益与辐射方向图和效率有关，和驻波比没有直接联系。  

**3. 解题思路**

- **考查知识点：** 对 SWR 的理解。  
- **核心判断：** SWR 高 → 匹配不好 → 有部分功率反射。  
- **区分陷阱：** 阻抗不是唯一对应值，不能过度解读成精确电阻值；效率和增益不能仅由 SWR 推断。  
- **选择原则：** 选与 SWR 含义直接对应的基本表述。

**4. 知识点总结**

- 驻波比（SWR）是反映发射机端口看到的负载与系统阻抗匹配情况的参数。  
- SWR = 1:1 → 完全匹配，无反射。  
- SWR > 1 → 匹配不好，SWR 值越大，反射功率越多。  
- SWR 不直接等于天线效率，也不等于天线增益。  
- 当 SWR = 4:1 时，大约 36% 的功率反射，64% 的功率传向天线。  

**最终答案**

**正确选项是：**  
**“从发射机的输出端口来看，天线系统的整体匹配情况不佳”**

## 第 470 题

<span data-tts-skip><em>MC1-0673 · 单选 · 适用 A/B/C 类</em></span>

多数发射机都在 SWR 超过一定值时降低输出功率。这是为了：

:::tip 正确答案
**保护发射机中的功率半导体器件**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 保护发射机中的功率半导体器件 ✓
- B. 防止烧断供电线路中的保险丝
- C. 防止传输线上的驻波超过限值
- D. 防止发射出去的无线电波带有过大的驻波

正确答案：A

</details>

**题解**

****1. 知识点解释****
- **驻波比（SWR）**：表示传输线与天线系统之间的阻抗匹配程度，定义为电压驻波的最大值与最小值之比，公式为：  
  $ \text{SWR} = \frac{V_{\text{max}}}{V_{\text{min}}} $  
  SWR过高（如超过2:1）会导致大量反射功率返回发射机，可能损坏功放电路。
- **功率半导体器件**：固态发射机的核心元件（如MOSFET、双极晶体管），对温度和功率承受能力敏感，需避免过载。

****2. 解题思路****
1. **明确问题核心**：发射机降低输出功率的保护目标是什么？
2. **排除干扰项**：
   - **防止烧断保险丝**：保险丝保护通常由过流保护电路直接处理，而非通过降低功率实现。
   - **防止传输线驻波超过限值**：驻波是传输线与天线匹配状态的物理现象，降低输出功率无法改变匹配状态，仅能减少反射功率的影响。
   - **防止无线电波驻波**：无线电波是辐射场，不形成驻波现象，此选项存在概念错误。
3. **关键逻辑**：  
   高SWR导致反射功率增加，功放输出级需承受额外功率损耗（$P_{\text{损耗}} = P_{\text{前向}} - P_{\text{辐射}}$），可能因过热或过压损坏半导体器件。

****3. 答案分析****
- **正确选项**：**保护发射机中的功率半导体器件**  
  高SWR导致反射功率增加，功放晶体管需承受更高的电压和电流应力（$V_{\text{DS}}$或$V_{\text{CE}}$），可能超出其安全工作区（SOA），触发保护机制降低输出功率以避免损坏。
- **错误选项分析**：
  - **防止烧断供电线路中的保险丝**：保险丝容量通常按最大设计功率选择，且保护动作由瞬时电流决定，而非反射功率。
  - **防止传输线上的驻波超过限值**：驻波比由阻抗匹配决定，与输出功率无关，降低功率无法改变驻波比。
  - **防止发射出去的无线电波带有过大的驻波**：无线电波是行波，不存在驻波概念，此选项混淆了传输线驻波与辐射波特性。

****4. 知识库引用****
- 根据《No-Nonsense Technician Class License Study Guide》中关于SWR保护的讨论：  
  "固态发射机在SWR过高时降低输出功率是为了保护输出放大器晶体管（Power Amplifier Transistors）"。  
  此文档直接支持正确答案，表明保护功率半导体器件是核心原因。

**最终结论**：发射机降低输出功率的核心目的是通过限制功放级的最大承受功率，防止功率半导体器件因反射功率导致的过热或电压击穿。
