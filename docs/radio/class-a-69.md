## 第 681 题

<span data-tts-skip><em>MC1-1373 · 单选 · 适用 A/B/C 类</em></span>

使用普通 12 伏铅酸蓄电池为电台供电存在什么潜在风险？

:::tip 正确答案
**如果通风不良，会有爆炸性气体聚集**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 如果通风不良，会有爆炸性气体聚集 ✓
- B. 有高电压，存在触电风险
- C. 会释放臭氧，进而污染大气层
- D. 若长时间闲置不用就可能自燃

正确答案：A

</details>

**题解**

铅酸电池在充电后期（尤其是过充时），正极板的水会被电解，产生氢气（H₂）和氧气（O₂）（化学反应：2H₂O → 2H₂↑ + O₂↑）。氢气是易燃气体，与空气混合后浓度达到4%-75%（爆炸极限）时，遇明火、电火花或高温（如电池接头打火）可能引发爆炸。

## 第 682 题

<span data-tts-skip><em>MC1-1374 · 单选 · 适用 A/B/C 类</em></span>

如果铅酸蓄电池的充电或放电过程过快会有什么风险？

:::tip 正确答案
**电池可能过热，甚至释放氢气，抬升爆炸风险**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 电池可能过热，甚至释放氢气，抬升爆炸风险 ✓
- B. 电压会变为负值，导致电池报废。这就是所谓“反极”
- C. 导致“记忆效应”，从而使电池的可用容量下降
- D. 可能导致过高的电池电压，抬升触电风险

正确答案：A

</details>

**题解**

**铅酸蓄电池快速充放电的后果解析**

**A. 电池可能会过热，甚至释放出可燃气体，甚至可能爆炸**
✓ **正确**。铅酸蓄电池快速充放电时会产生大量热量，导致电池温度急剧上升。过快充电会加速电解液中的电解反应，产生大量氢气和氧气（尤其是在充电末期）。这些气体在密闭空间中积累并遇到火花时可能引起爆炸。此外，过热会加速电极板硫化、变形和活性物质脱落，严重缩短电池寿命。

**B. 电压会将为负值**
✗ **错误**。铅酸蓄电池过快放电不会导致电压变为负值。实际上，快速放电会导致电压迅速下降，但最低只会降至0伏附近，不会变成负值。过快放电会造成电极板硫酸盐化严重，内阻增大，但这不会反转电池的极性。

**C. "记忆效应"将使电池的可用容量减小**
✗ **错误**。"记忆效应"主要出现在镍镉(NiCd)和部分镍氢(NiMH)电池中，不是铅酸蓄电池的典型问题。铅酸蓄电池容量减小主要是因为硫酸盐化、活性物质脱落、电极板弯曲等原因，而非记忆效应。过快充放电确实会减小电池容量，但机制不同。

**D. 可能会产生过高的充电电压，引起触电的危险**
✗ **错误**。快速充电可能导致充电电压升高，但正常情况下不会达到足以引起严重触电危险的程度。现代充电器通常有电压限制和保护机制。更危险的是电池过热和气体产生可能导致的爆炸风险，而非触电风险。

综上所述，铅酸蓄电池过快充放电的主要危险是过热和可能的爆炸风险。
