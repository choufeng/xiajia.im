<span data-tts-skip><em>MC3-0138 · 多选 · 适用 A/B/C 类</em></span>

关于业余无线电台在通信过程中使用的语言，正确的做法为:

:::tip 正确答案
**在通信过程中使用明语**<span data-tts-skip>（A）</span> · **在通信过程中使用业余无线电领域公认的缩略语、简语**<span data-tts-skip>（B）</span> · **在通信过程中使用公开的技术体制和通信协议**<span data-tts-skip>（C）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 在通信过程中使用明语 ✓
- B. 在通信过程中使用业余无线电领域公认的缩略语、简语 ✓
- C. 在通信过程中使用公开的技术体制和通信协议 ✓
- D. 在通信过程中使用自创的特殊缩略语

正确答案：A、B、C

</details>

**题解**

**1. 相关知识点解释**
**《业余无线电台管理办法》第三十五条**：  
使用业余无线电台的单位或个人需遵守以下通信规范：  
- **明语**：通信内容应使用通俗易懂的语言（如中文、英语），而非加密或隐晦表达。  
- **公认缩略语/简语**：仅限使用国际业余无线电领域通用的缩略语（如Q简语、QSO、QRS等）和简语（如“73”表示“致敬”）。  
- **公开技术体制与协议**：通信需采用公开、标准化的技术标准（如模拟/数字通信模式、频段划分规则）。  
- **禁止自创缩略语**：不得使用未被国际业余无线电界公认的自定义缩略语或暗语，以避免误解和违规风险。  

**核心依据**：  
- 《业余无线电台管理办法》第三十五条规定了通信语言和协议的合规性要求。  
- 《ITU无线电规则》和《中华人民共和国无线电频率划分规定》对业余业务通信规范有补充说明。

**2. 解题思路与分析过程**
1. **明确法规要求**：  
   通信语言需符合国家无线电管理机构（如工业和信息化部）及国际业余无线电联盟（IARU）的规范，确保通信透明性、可追溯性和技术兼容性。  

2. **逐一分析选项**：  
   - **在通信过程中使用明语**：  
     正确。明语是通信的基础，避免因语言歧义导致干扰或违规。  
   - **在通信过程中使用业余无线电领域公认的缩略语、简语**：  
     正确。国际通用的缩略语（如QSL表示“收妥”）提升通信效率且符合规范。  
   - **在通信过程中使用公开的技术体制和通信协议**：  
     正确。例如使用公开的FT8、PSK31等数字模式，或SSB、CW等模拟模式。  
   - **在通信过程中使用自创的特殊缩略语**：  
     错误。自创缩略语可能引发误解，且违反《业余无线电台管理办法》第三十五条。  

3. **结论**：  
   前三个选项为正确做法，最后一个选项为错误做法。

**3. 答案分析**
**正确答案**：  
- **在通信过程中使用明语**  
- **在通信过程中使用业余无线电领域公认的缩略语、简语**  
- **在通信过程中使用公开的技术体制和通信协议**  

**错误答案**：  
- **在通信过程中使用自创的特殊缩略语**  
  - **原因**：自创缩略语不符合《业余无线电台管理办法》第三十五条，且可能被视为变相加密通信，违反“通信内容应公开透明”的原则。  

**依据文档**：  
- 《业余无线电台管理办法》第三十五条  
- 《ITU无线电规则（2024年版）卷1》第25条关于业余业务的规定  
- 《中华人民共和国无线电频率划分规定》1.3.39业余业务定义  

**4. 扩展说明**
- **明语与缩略语的平衡**：  
  在保证通信效率的同时，需优先使用明语。例如在通联记录（QSO）中，呼号、信号报告（如RST编码）需用明语，但“QSL”“QRZ”等通用缩略语可合理使用。  
- **技术协议公开性示例**：  
  使用公开标准的FT8、JS8Call等数字模式符合要求，而使用未经公开的私有协议（如自定义编码）则违规。  

**总结**：  
业余无线电通信需严格遵守“语言标准化、技术公开化”的原则，确保合法性和全球互通性。

**题解**

**法律来源**

擅自设台、擅自使用频率并严重干扰无线电通信秩序，可能被判处有期徒刑、拘役或管制并处罚金；这种涉及刑事责任的规定出自《中华人民共和国刑法》。

记忆关键词：**判刑 → 刑法**。
