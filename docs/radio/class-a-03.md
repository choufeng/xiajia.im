## 第 22 题

<span data-tts-skip><em>MC1-0022 · 单选 · 适用 A/B/C 类</em></span>

国际业余无线电联盟支持会员协会在发展业余无线电时把它看成一种：

:::tip 正确答案
**国家资源**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 国家资源 ✓
- B. 拉动经济的措施
- C. 休闲娱乐手段
- D. 国防后备队伍

正确答案：A

</details>

**题解**

**1. 相关知识点解释**
国际业余无线电联盟（IARU）的核心宗旨是促进全球业余无线电技术的发展与应用。根据其官方文件及国际电信联盟（ITU）相关规则，业余无线电被视为一种**国家资源**，主要体现在以下方面：
- **频谱资源**：业余无线电频段是国际电信联盟（ITU）专门为非商业通信和技术研究保留的稀缺资源（参考《ITU 无线电规则（2024年版）卷1：条款》1.56条）。
- **应急通信能力**：业余无线电在自然灾害或紧急情况下可作为国家应急通信体系的补充力量（参考《业余无线电台管理办法》第三条）。
- **技术人力资源**：通过业余无线电活动培养无线电技术人才，支持国家在通信、电子等领域的长期发展。

**2. 解题思路与分析过程**
- **题干关键词**：题目关键在于理解IARU对会员协会发展业余无线电的定位，而非单纯讨论业余无线电的具体用途。
- **选项对比分析**：
  1. **国家资源**：直接对应IARU倡导的频谱保护、应急通信支援及技术人才培养目标，符合其战略定位。
  2. **拉动经济的措施**：虽然业余无线电设备制造和展会可能间接促进经济，但这并非IARU的核心职能（参考《No-Nonsense Technician Class License Study Guide》关于业余无线电非商业性质的定义）。
  3. **休闲娱乐手段**：通联（QSO）、竞赛等娱乐性活动是业余无线电的组成部分，但IARU更强调其技术和社会价值，而非单纯娱乐。
  4. **国防后备队伍**：尽管业余无线电爱好者可能参与应急通信支援，但其角色是民间辅助力量，而非国防军事体系的直接组成部分。

**3. 答案选择依据**
正确答案为**国家资源**，理由如下：
- **政策法规支持**：根据《业余无线电台管理办法》第三条，业余无线电被明确限定为“相互通信、技术研究和自我训练”，强调其资源属性而非商业或军事用途。
- **国际规则依据**：ITU《无线电规则》1.56条将业余业务定义为“自我训练、相互通信和技术研究”，与国家资源的定位一致。
- **实际应用场景**：IARU鼓励会员协会将业余无线电纳入国家频谱规划，并通过应急通信演练提升社会公共服务能力（参考《ITU 无线电规则（2024年版）卷3：决议和建议》第673号决议）。

**引用文档**
- 《ITU 无线电规则（2024年版）卷1：条款》1.56条（业余业务定义）
- 《业余无线电台管理办法》第三条（业余无线电用途限制）
- 《No-Nonsense Technician Class License Study Guide》（业余无线电非商业性质）
- 《ITU 无线电规则（2024年版）卷3：决议和建议》第673号决议（应急通信支持）

## 第 24 题

<span data-tts-skip><em>MC1-0024 · 单选 · 适用 A/B/C 类</em></span>

关于无线电通信的正确说法：

:::tip 正确答案
**无线电通信是指利用无线电波进行的符号、信号、文字、图像、声音或其他信息的传输、发射或接收**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 无线电通信是指利用无线电波进行的符号、信号、文字、图像、声音或其他信息的传输、发射或接收 ✓
- B. 无线电通信包括利用光在内的所有电磁波所进行的各种通信
- C. 利用无线电波进行的符号、信号、文字、图像、声音以外的信息传输不属于无线电通信
- D. 产生无线电波并用其加热属于无线电通信的一种应用

正确答案：A

</details>

**题解**

****1. 相关知识点解释****
- **无线电通信的定义**  
  根据《ITU 无线电规则（2024年版）卷1：条款》1.6条：  
  **无线电通信**（Radio Communication）是利用无线电波的电信（《组织法》），而电信的定义（1.3条）包括对符号、信号、文字、图像、声音或任何性质信息的传输、发射或接收（《组织法》）。  
  此外，无线电波的定义（1.5条）为：**频率规定在3 000 GHz以下的电磁波**，且不使用人工波导传播。

- **非无线电通信的应用**  
  根据1.15条，**工业、科学和医疗（ISM）应用**中，射频能量用于局部加热、医疗等非通信领域，属于非通信用途。

****2. 解题思路与分析过程****
1. **选项分析**  
   - **选项1**：  
     “无线电通信是指利用无线电波进行的符号、信号、文字、图像、声音或其他信息的传输、发射或接收”  
     - **依据**：ITU规则1.6条明确将无线电通信定义为“利用无线电波的电信”，而电信的定义包含符号、信号、文字、图像、声音等信息（1.3条）。  
     - **结论**：此为正确描述。

   - **选项2**：  
     “无线电通信包括利用光在内的所有电磁波所进行的各种通信”  
     - **依据**：无线电波的定义（1.5条）限定频率范围为3 000 GHz以下，而光属于更高频率的电磁波（如红外、可见光），属于光学通信范畴，不在无线电通信范围内。  
     - **结论**：此为错误描述。

   - **选项3**：  
     “利用无线电波进行的符号、信号、文字、图像、声音以外的信息传输不属于无线电通信”  
     - **依据**：电信的定义明确包含“任何性质的信息”（1.3条），因此符号、信号等以外的信息传输仍属于无线电通信。  
     - **结论**：此为错误描述。

   - **选项4**：  
     “产生无线电波并用其加热属于无线电通信的一种应用”  
     - **依据**：ISM应用（1.15条）明确将射频能量用于加热等非通信领域，与无线电通信无关。  
     - **结论**：此为错误描述。

2. **逻辑验证**  
   - 仅选项1符合ITU规则中对无线电通信的定义，其余选项均与规则冲突。

****3. 答案分析****
- **正确答案**：  
  “无线电通信是指利用无线电波进行的符号、信号、文字、图像、声音或其他信息的传输、发射或接收”  
  - **依据文档**：  
    - 《ITU 无线电规则（2024年版）卷1：条款》1.3条（电信定义）、1.6条（无线电通信定义）。

- **错误选项分析**：  
  - **选项2**：将光纳入无线电通信范围，违反无线电波的频率限定（1.5条）。  
  - **选项3**：否定“其他信息”的传输，与电信定义（1.3条）矛盾。  
  - **选项4**：加热属于ISM应用（1.15条），与通信无关。

****总结****
本题考查无线电通信的核心定义及其与其他技术的区分。关键在于准确理解ITU规则中对无线电波、电信和非通信用途的界定，避免混淆无线电通信与其他电磁波应用（如光学通信、ISM加热）。

## 第 29 题

<span data-tts-skip><em>MC4-0029 · 多选 · 适用 A/B 类</em></span>

设置、使用业余无线电台，下列哪些条件符合规定：

:::tip 正确答案
**使用的无线电发射设备依法取得型号核准**<span data-tts-skip>（A）</span> · **型号核准证载明的频率范围包含业余业务频段**<span data-tts-skip>（B）</span> · **使用的自制、改装、拼装等未取得型号核准的无线电发射设备符合国家标准和国家无线电管理规定**<span data-tts-skip>（C）</span> · **使用的自制、改装、拼装等未取得型号核准的无线电发射设备的无线电发射频率范围仅限于业余业务频段**<span data-tts-skip>（D）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 使用的无线电发射设备依法取得型号核准 ✓
- B. 型号核准证载明的频率范围包含业余业务频段 ✓
- C. 使用的自制、改装、拼装等未取得型号核准的无线电发射设备符合国家标准和国家无线电管理规定 ✓
- D. 使用的自制、改装、拼装等未取得型号核准的无线电发射设备的无线电发射频率范围仅限于业余业务频段 ✓

正确答案：A、B、C、D

</details>

**题解**

**1. 相关知识点解释**
本题考查《业余无线电台管理办法》第七条关于**设置、使用业余无线电台的设备要求**。核心知识点如下：  
- **型号核准要求**：依法取得型号核准的无线电发射设备，其核准证载明的频率范围必须包含业余业务频段。  
- **自制/改装设备要求**：未取得型号核准的自制、改装、拼装设备需同时满足两个条件：  
  - 符合国家标准和国家无线电管理规定；  
  - 发射频率范围**仅限于业余业务频段**。  

（引用文档：《业余无线电台管理办法》第二章许可管理第七条）

**2. 解题思路与分析过程**
题目要求判断四个条件是否符合规定，需逐一验证：  
1. **选项一**：设备取得型号核准  
   - 根据《业余无线电台管理办法》第七条第三项，符合条件。  
2. **选项二**：核准证频率范围包含业余频段  
   - 同一法规明确要求型号核准证需覆盖业余业务频段。  
3. **选项三**：未核准设备符合国家标准和规定  
   - 直接引用法规原文，属于自制设备的合规性要求。  
4. **选项四**：未核准设备频率范围仅限业余频段  
   - 法规明确限定自制设备的发射范围**仅限**业余频段。  

**3. 答案分析**
**所有选项均符合规定**，具体分析如下：  
- **选项一**：设备取得型号核准是基本要求，确保其技术指标符合国家标准（如频率稳定性、发射功率等）。  
- **选项二**：型号核准证需明确覆盖业余业务频段，避免设备在非授权频段发射信号。  
- **选项三**：自制设备虽未通过型号核准，但需通过技术检测证明其符合国家标准和无线电管理规定（如杂散辐射控制）。  
- **选项四**：自制设备的发射范围**严格限定**于业余频段，防止对其他业务（如航空、应急通信）造成干扰。  

（引用文档：《业余无线电台管理办法》第十四条明确要求对自制设备进行技术检测）

**4. 重要结论**
**正确答案**：所有选项均符合规定。  
**法规依据**：
