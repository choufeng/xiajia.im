**题解**

以下内容由AI生成（Anthropic Claude），仅供参考。（审核注：具体信标频率见《IARU Region 3 Interim Band Plan》）

**题目分析**

这道题考查的是IARU（国际业余无线电联盟）信标台工作频率的相关知识。IARU信标台是用于传播研究和频率监测的特殊电台，业余电台应避免在这些频率附近发射以免造成干扰。

**相关技术原理**

IARU信标台系统是一个全球性的传播监测网络，这些信标台在特定频率上连续发射信号，用于：
1. 监测电离层传播条件
2. 帮助业余电台了解各频段的传播状况  
3. 为传播预测提供实时数据

为保护这些信标台的正常工作，业余电台应避免在信标频率±500Hz范围内发射。

**选项分析**

让我们分析IARU信标台在各个业余频段的标准工作频率：

**第一个选项：14.100MHz、18.110MHz、21.150MHz、24.930MHz、28.200MHz**
- 14.100MHz：正确，这是20米波段的IARU信标频率
- 18.110MHz：正确，这是17米波段的IARU信标频率
- 21.150MHz：正确，这是15米波段的IARU信标频率
- 24.930MHz：正确，这是12米波段的IARU信标频率
- 28.200MHz：正确，这是10米波段的IARU信标频率

**第二个选项：7.100MHz、10.070MHz、14.100MHz、21.100MHz、28.200MHz**
- 包含了一些非标准频率，如21.100MHz应为21.150MHz

**第三个选项：7.150MHz、14.110MHz、18.150MHz、21.150MHz、28.150MHz**
- 多个频率不准确，如14.110MHz应为14.100MHz

**第四个选项：14.150MHz、18.100MHz、21.200MHz、24.930MHz、28.200MHz**
- 多个频率错误，如14.150MHz应为14.100MHz，21.200MHz应为21.150MHz

**正确答案确认**

标准的IARU信标频率为：
- 14.100MHz（20米波段）
- 18.110MHz（17米波段）
- 21.150MHz（15米波段）
- 24.930MHz（12米波段）
- 28.200MHz（10米波段）

经过仔细核对，第一个选项"14.100MHz、18.110MHz、21.150MHz、24.930MHz、28.200MHz"最符合IARU信标台的标准工作频率。

**知识点总结**

1. **IARU信标系统**：全球传播监测网络，用于电离层研究
2. **保护要求**：业余电台应避免在信标频率±500Hz范围内发射
3. **主要信标频率**：覆盖10-28MHz的主要短波业余频段
4. **实际应用**：在选择工作频率时要考虑避让信标频率，特别是进行DX通信时

这些信标频率是业余无线电操作中的重要参考，既要避免对其造成干扰，也可以利用其信号来判断传播条件。
