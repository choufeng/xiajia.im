在为同轴馈线安装避雷器时应当注意什么？

:::tip 正确答案
**将所有避雷器的地线接到同一个金属条带上，然后将条带可靠连到室外的接地处**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 将所有避雷器的地线接到同一个金属条带上，然后将条带可靠连到室外的接地处 ✓
- B. 在每个避雷器的地线连接处安装开关以在发信时断开，防止射频电流损伤避雷器
- C. 将每个避雷器的接地连线都单独引出，然后将它们与电台的地线连在一起
- D. 可用廉价的氖灯或气体放电管自制避雷器。这样的 DIY 可谓经济实用，效果卓著

正确答案：A

</details>

**题解**

**题解：同轴馈线避雷器安装注意事项**

****1. 知识点解释****
避雷器用于保护无线电设备免受雷电和静电放电的损害。同轴馈线避雷器的接地方式需满足以下要求：
- **等电位接地**：所有避雷器的地线需连接至同一接地点，避免电位差导致的干扰或损坏。
- **低阻抗路径**：接地线应短而直，减少高频电流的感抗。
- **独立接地**：避雷器接地应独立于设备电源地，防止雷电流通过设备外壳引入干扰。

****2. 解题思路与分析****
逐一分析选项：
1. **选项一**（正确）：  
   - 将所有避雷器的地线接到同一金属条带，确保等电位连接，再通过单点接地引至室外接地点。  
   - 符合“共用接地母线”的规范，避免接地环路和电位差。

2. **选项二**（错误）：  
   - 安装开关会导致射频电流路径断开，可能损坏避雷器或设备。  
   - 避雷器需始终保持低阻抗状态，开关可能因故障或误操作失效。

3. **选项三**（错误）：  
   - 单独引出接地可能形成接地环路，导致不同避雷器间电位差，引发干扰或损坏。  
   - 接地线长度差异会引入感抗，影响防雷效果。

4. **选项四**（错误）：  
   - 自制避雷器（如氖灯或气体放电管）无法保证稳定性和耐受高能量雷击的能力，存在安全隐患。  
   - 工业级避雷器需满足特定的击穿电压、响应时间和放电能力标准。

****3. 正确答案****
**将所有避雷器的地线接到同一个金属条带上，然后将条带可靠连到室外的接地处**

****4. 答案分析****
- **选项一**符合避雷器接地的核心原则（等电位、单点接地），确保雷电流通过统一路径泄放，减少对设备的冲击。
- **选项二**中开关的存在破坏了避雷器的连续保护功能，且射频电流需完整回路，断开会导致反射和驻波。
- **选项三**的独立接地可能因电位差产生环流，尤其在高频下，感抗差异会放大干扰。
- **选项四**自制器件无法通过专业测试（如IEC 61643-1的浪涌测试），可靠性不足。

****引用依据****
- **No-Nonsense Technician Class License Study Guide** 中提到接地导体应“短而直，避免尖锐弯曲”（对应等电位和低阻抗路径要求）。
- 工程实践普遍推荐“共用接地母线 + 单点接地”以消除电位差干扰（参考IEEE C62.41.2-2002标准）。

****总结****
避雷器接地需兼顾电气安全和射频性能，统一接地点和低阻抗路径是关键。自制或非标准设计可能引发不可逆的设备损坏风险。

## 第 674 题

<span data-tts-skip><em>MC1-1366 · 单选 · 适用 A/B/C 类</em></span>

假如接触电压相同，则触及带有射频电压（例如，频率不低于 LF）的裸露导线与触及带有直流或交流 50Hz 电压的裸露导线相比，人体所受的安全威胁有什么不同？

:::tip 正确答案
**致死风险有所下降，但是灼伤皮肤或深层皮下组织的风险显著上升**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 致死风险有所下降，但是灼伤皮肤或深层皮下组织的风险显著上升 ✓
- B. 更容易导致神经系统损伤或使心肺功能紊乱，存在更高的致死风险
- C. 射频交流电从不威胁人身安全，所以发射机的天线都可以随意触摸
- D. 触及不同频率但电压相同的交流电，人体当然面临相同的安全威胁

正确答案：A

</details>

**题解**

**1. 相关知识点解释**
- **射频电流的特性**：射频（RF）电流通常指频率高于低频（LF, 如50Hz）的交流电。射频电流在人体表面产生显著的**皮肤效应**（Skin Effect），导致能量集中在皮肤表层，产生大量热量，可能灼伤皮肤或深层皮下组织。  
- **直流/低频交流电的特性**：直流或50Hz交流电主要通过电击效应影响人体，可能引起肌肉痉挛、呼吸抑制、心室颤动等致命风险。  
- **安全威胁的差异**：射频电流的热效应更显著，而低频电流的电生理效应（如干扰心脏节律）风险更高。

**2. 解题思路与分析过程**
- **关键比较点**：  
  - **致死风险**：射频电流因频率高，难以穿透体内深层组织（皮肤效应），因此对心脏等器官的电生理干扰较弱，致死风险相对较低。  
  - **灼伤风险**：射频电流在皮肤表层集中，导致局部温度迅速升高，灼伤风险显著增加。  
- **排除干扰项**：  
  - 第二个选项提到“更高致死风险”与射频特性矛盾。  
  - 第三个选项声称“射频交流电从不威胁人身安全”明显错误（高电压仍可致伤）。  
  - 第四个选项忽视了频率对生物效应的影响，直接否定差异，不符合科学依据。  

**3. 答案选择依据**
根据**生物电磁学原理**（如ICNIRP指南）和**电生理效应研究**：  
- 射频电流的**热效应主导**，导致皮肤或深层组织灼伤（如$ P = I^2R $，功率集中在表层）。  
- 低频电流（50Hz）更易通过**电击效应**引发心室颤动（致命风险）。  

最终选择：  
**致死风险有所下降，但是灼伤皮肤或深层皮下组织的风险显著上升**  

**引用文档**
《No-Nonsense Technician Class License Study Guide》（电气原理部分）指出射频电流的皮肤效应与热效应是主要安全风险（参考文档名原文）。

## 第 675 题

<span data-tts-skip><em>MC1-1367 · 单选 · 适用 A/B/C 类</em></span>

如果用两手分别接触电压有效值相同但频率不同的电路的两个端点，则所受安全威胁由大到小可以排序为：

:::tip 正确答案
**工频交流电、HF 射频交流电、UHF 射频交流电**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 工频交流电、HF 射频交流电、UHF 射频交流电 ✓
- B. UHF 射频交流电、HF 射频交流电、工频交流电
- C. HF 射频交流电、工频交流电、UHF 射频交流电
- D. HF 射频交流电、UHF 射频交流电、工频交流电

正确答案：A

</details>

**题解**

**1. 相关知识点解释**
- **工频交流电**：指频率为50Hz或60Hz的交流电，是日常电力系统使用的标准频率。国际电工委员会（IEC）标准表明，该频率范围的电流最易引起心室颤动（致命电击风险）。
- **HF射频交流电**：高频射频电流（3-30MHz），其通过人体时受**集肤效应**影响，电流主要分布于皮肤表面，对心脏等内脏的直接伤害风险降低。
- **UHF射频交流电**：超高频射频电流（300MHz-3GHz），集肤效应更显著，电流更趋近于皮肤表层流动，进一步减少对重要器官的直接伤害。
- **电击危险性与频率的关系**：  
  根据IEC 60479-1标准，人体对电流的敏感性随频率变化而变化。工频（50-60Hz）电流最容易引发心室颤动，是电击致死的高风险频率；随着频率升高至射频范围（>1kHz），危险性逐渐降低。

**2. 解题思路与分析过程**
- **步骤1：明确危险性核心机制**  
  电击致命风险主要由电流通过心脏引发心室颤动决定。工频电流（50-60Hz）最容易诱发这一效应。
  
- **步骤2：分析频率对电流路径的影响**  
  HF和UHF射频电流因集肤效应，电流集中在皮肤表面流动，减少对心脏的直接冲击。UHF（更高频率）的集肤效应比HF更显著，因此UHF的危险性最低。

- **步骤3：对比选项排序**  
  根据危险性排序：工频（50Hz）> HF射频（如10MHz）> UHF射频（如1GHz）。唯一符合这一逻辑的选项为：**工频交流电、HF射频交流电、UHF射频交流电**。

**3. 答案分析**
- **正确答案**：工频交流电、HF射频交流电、UHF射频交流电  
  （危险性由高到低排序）。
- **错误选项分析**：  
  - **UHF射频交流电、HF射频交流电、工频交流电**：颠倒了工频与射频的危险性顺序，违反IEC标准。  
  - **HF射频交流电、工频交流电、UHF射频交流电**：将HF射频置于工频之前，与工频电击致死风险最高矛盾。  
  - **HF射频交流电、UHF射频交流电、工频交流电**：同样将工频排在最后，明显错误。

**4. 参考资料**
- IEC 60479-1: 《电流通过人体的效应》  
- No-Nonsense Technician Class License Study Guide（关于工频电流危险性的描述）  

**结论**：工频交流电因易引发心室颤动，危险性最高；HF射频次之；UHF射频因集肤效应最安全。正确选项为第一个。

## 第 676 题

<span data-tts-skip><em>MC1-1368 · 单选 · 适用 A/B/C 类</em></span>

如果不得已，必须带电检修由市电供电的无线电设备，则应做到：

:::tip 正确答案
**双脚与地绝缘，单手操作，另一只手不触摸机壳等任何与电路或接地有关的金属件**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 双脚与地绝缘，单手操作，另一只手不触摸机壳等任何与电路或接地有关的金属件 ✓
- B. 双脚与地绝缘，单手操作，另一只手通过触摸机壳或水管等接地物件探测是否有电
- C. 只要设备外壳良好接地，双脚是否与地绝缘、双手是否同时操作都不存在安全风险
- D. 只要设备外壳与地绝缘，双脚是否与地绝缘、双手是否同时操作都不存在安全关系

正确答案：A

</details>

**题解**

**1. 相关知识点解释**
本题考查电气安全操作规范，核心是防止电流通过人体（尤其是心脏）形成回路。  
- **电流回路风险**：当人体同时接触带电体和地（或接地金属件）时，电流会通过人体形成回路，导致触电。  
- **单手操作原则**：仅用单手操作带电设备，避免电流同时流经双手（可能经过心脏）。  
- **绝缘措施**：保持身体与地绝缘，防止电流通过地面形成回路。

**2. 解题思路与分析过程**
- **目标**：判断哪种操作方式最安全，避免形成电流通路。  
- **关键逻辑**：  
  - 若设备带电，操作者需阻断电流通过人体的路径。  
  - 双脚绝缘可防止与地面形成回路；单手操作可减少电流流经心脏的可能性。  
  - 若另一只手触摸接地金属件（如机壳、水管），可能形成回路，导致触电。

**3. 答案分析**
**正确选项**：  
**双脚与地绝缘，单手操作，另一只手不触摸机壳等任何与电路或接地有关的金属件**  
**原因**：  
- 此操作完全阻断了电流通过人体的路径。即使设备漏电，电流也无法通过人体与地面或接地金属形成回路，安全性最高。  

**错误选项分析**：  
1. **双脚与地绝缘，单手操作，另一只手通过触摸机壳或水管等接地物件探测是否有电**：  
   - 危险操作。若设备带电，手触摸接地物件会与单手操作形成回路，电流流经人体（可能经过心脏），导致触电。  

2. **只要设备外壳良好接地，双脚是否与地绝缘、双手是否同时操作都不存在安全风险**：  
   - 错误假设。即使外壳接地，若操作者同时接触带电部分和接地金属（如机壳），仍会形成回路导致触电。  

3. **只要设备外壳与地绝缘，双脚是否与地绝缘、双手是否同时操作都不存在安全关系**：  
   - 逻辑错误。外壳绝缘仅能防止外壳带电，但若操作者直接接触内部带电部分且未绝缘双脚，仍可能通过地面形成回路。

**4. 结论**
电气安全的核心是**阻断电流回路**。正确做法是：双脚绝缘（与地隔离）、单手操作（避免电流流经心脏）、另一只手远离接地金属件（防止形成回路）。其他选项均存在直接或间接导致触电的风险。

## 第 678 题

<span data-tts-skip><em>MC1-1370 · 单选 · 适用 A/B/C 类</em></span>

即使设备的电源线已经拔掉，检修时仍可能遇到什么安全风险？

:::tip 正确答案
**充满高电压的电容器可能让维修者遭遇电击风险**<span data-tts-skip>（A）</span>
:::

- B. 地磁活动可在变压器中激起高压，电到维修人员
- C. 打开电源设备或电子管线性放大器的机箱，其内置保险丝就会烧断
- D. 如果打开机箱，静电放电就可能损坏设备的接地系统

正确答案：A

</details>

**题解**

**1. 相关知识点解释**
- **电容器储能特性**：电容器在电路中可储存电能，即使设备断电后，高压电容器（如电源滤波电容、闪光灯电容）仍可能长时间保持残余电荷，存在电击风险。
- **地磁活动影响**：地磁暴可能引发地磁感应电流（GIC），主要影响长距离电网或通信线路，但对断电设备的局部变压器影响极小。
- **保险丝工作原理**：保险丝通过熔断保护电路，通常在过流时动作，与机箱开合无直接关联。
- **静电放电（ESD）**：静电放电可能损坏敏感电子元件，但接地系统的损坏通常由物理破坏或腐蚀导致，而非直接由开箱操作引发。

**2. 解题思路与分析**
- **选项1**：**正确**。高压电容器在断电后可能残留危险电压（例如电解电容在电源断开后可能保持数百伏电压），需通过专用放电工具处理。
- **选项2**：**错误**。地磁活动对设备内部变压器的直接影响极小，且断电后电路无电流路径，无法激发电压。
- **选项3**：**错误**。保险丝烧断需满足过流条件，开箱操作本身不会导致电流突变。
- **选项4**：**错误**。静电放电可能损坏电路元件，但不会直接破坏设备的接地系统（接地系统损坏通常因物理断裂或腐蚀）。

**3. 答案选择原因**
**选项1**描述的电容器电击风险是电子设备维修中最常见的安全隐患。根据电气安全规范（如IEC 60950-1），要求维修前对高压电容器进行强制放电处理。知识库中“电容器放电”部分明确指出储能电容的残余电压风险，进一步支持此结论。

**正确答案**：  
**充满高电压的电容器可能让维修者遭遇电击风险**
