## 第 372 题

<span data-tts-skip><em>MC1-0433 · 单选 · 适用 A/B/C 类</em></span>

以下哪种调制方式被广泛应用于 VHF 或 UHF 本地通联？

:::tip 正确答案
**FM**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. FM ✓
- B. SSB
- C. PSK
- D. AM

正确答案：A

</details>

**题解**

**1. 相关知识点解释**
- **VHF/UHF频段特性**：  
  VHF（30 MHz–300 MHz）和UHF（300 MHz–3 GHz）频段具有较高的频率，适合视距传播（Line-of-Sight），常用于本地短距离通信（如对讲机、业余无线电通联）。  
- **调制方式特点**：  
  - **FM（调频）**：通过改变载波频率反映音频信号，抗干扰能力强，音频质量高，但占用带宽较宽（通常10-15 kHz）。  
  - **SSB（单边带调制）**：仅传输一个边带，节省带宽（约3 kHz）和功率，适合远距离弱信号通信（如HF波段）。  
  - **PSK（相移键控）**：数字调制方式，常用于数据传输（如Packet Radio），需复杂解调设备。  
  - **AM（调幅）**：通过载波幅度变化传递信号，结构简单但效率低，带宽较宽（约6 kHz），易受干扰。

**2. 解题思路与分析过程**
- **应用场景分析**：  
  VHF/UHF本地通联以短距离、高可靠性和易操作性为目标，需优先选择抗干扰能力强、设备简单的调制方式。  
- **选项对比**：  
  - **FM**：抗干扰能力强，音频质量高，适合本地短距离通信（如对讲机）。  
  - **SSB**：带宽窄、效率高，但需精确调谐和复杂设备，主要用于远距离通信。  
  - **PSK**：依赖数字处理，适合数据传输而非语音通联。  
  - **AM**：带宽宽、效率低，逐渐被替代。  
- **知识库验证**：  
  《No-Nonsense Technician Class License Study Guide》提到，VHF/UHF语音中继常用FM，而SSB适用于长距离弱信号通信（T8A04、T8A07）。ITU文件未提及AM/PSK在VHF/UHF本地通联中的主导地位。

**3. 答案分析**
**答案：FM**  
- **选择原因**：  
  FM在VHF/UHF频段被广泛采用，因其抗干扰能力、设备普及性和良好的音频质量，完全符合本地短距离通联需求。  
- **其他选项排除**：  
  - **SSB**：虽带宽窄，但需复杂设备和精确调谐，适合远距离而非本地通联。  
  - **PSK**：数字调制需数据传输场景，语音通信中应用较少。  
  - **AM**：传统调幅方式，效率低且易受干扰，已逐渐淘汰。

**引用文档**
- **《No-Nonsense Technician Class License Study Guide》**：T8A04、T8A07部分明确说明FM在VHF/UHF语音通信中的主流应用。  
- **ITU 无线电规则（2024年版）**：未直接提及VHF/UHF本地通联的调制选择，但支持SSB用于HF远距离通信（附录11）。

## 第 373 题

<span data-tts-skip><em>MC1-0434 · 单选 · 适用 A/B/C 类</em></span>

以下哪种调制方式被广泛应用于长距离和弱信号情况下的 VHF 或 UHF 话音通联？

:::tip 正确答案
**SSB**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. SSB ✓
- B. AM
- C. FM
- D. PM

正确答案：A

</details>

**题解**

**1. 知识点解释**
本题涉及无线电通信中的调制方式及其应用场景。  
- **SSB（单边带调制）**：通过抑制载波并仅传输一个边带（上边带或下边带），显著节省带宽（典型值3 kHz）和发射功率。其能量集中于单一边带，适用于弱信号和远距离通信。  
- **AM（调幅）**：保留完整载波和两个对称边带，带宽较宽（约6 kHz），功率效率低（大部分功率用于载波），适用于广播但不适合弱信号环境。  
- **FM（调频）**：通过改变载波频率传递信息，带宽较宽（VHF/UHF典型为10–15 kHz），音质较好但抗干扰能力弱，适合本地高质量通信。  
- **PM（调相）**：与FM相关，常用于数字通信，但在语音通信中应用较少。

**2. 解题思路**
- **核心需求**：长距离和弱信号场景需要**高效利用功率和带宽**的调制方式。  
- **关键对比**：  
  - SSB的窄带宽（3 kHz）允许更多信号共存，且能量集中于单一边带，提升弱信号接收可靠性。  
  - FM/PM带宽过宽，占用频谱资源多，且FM的“捕获效应”会压制弱信号。  
  - AM的载波消耗大部分功率，导致弱信号下通信质量差。

**3. 答案分析**
**正确选项：SSB**  
- **SSB的优势**：  
  - 能量效率高（无载波浪费），适合远距离弱信号场景。  
  - 带宽窄（3 kHz），减少噪声干扰，提升接收灵敏度。  
- **其他选项的缺陷**：  
  - **FM**：带宽宽（10–15 kHz），功率分散，且“捕获效应”导致弱信号易被压制。  
  - **AM**：载波消耗大量功率，弱信号下语音失真严重。  
  - **PM**：主要用于数字通信，语音应用中普及度低。  

**4. 知识库引用**
- **文档名称**：No-Nonsense Technician Class License Study Guide  
  - **内容**：明确指出“SSB比FM更适合VHF/UHF长距离弱信号通信，因其能量效率更高”（对应T8A03题解析）。  
- **ITU-R标准**：  
  - 《B部分 –单边带（SSB）系统》规定SSB的必要带宽不超过4.5 kHz，无用边带衰减≥35 dB，强化其抗干扰能力（卷2附录）。

**总结**
**SSB是唯一同时满足窄带宽和高功率效率的调制方式**，特别适合VHF/UHF频段的远距离弱信号话音通联。其他选项在带宽占用或功率分配上存在明显缺陷，无法满足题干需求。

## 第 374 题

<span data-tts-skip><em>MC1-0435 · 单选 · 适用 A/B/C 类</em></span>

以下哪种调制方式被广泛应用于 HF 话音通联？

:::tip 正确答案
**SSB**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. SSB ✓
- B. AM
- C. FM
- D. PM

正确答案：A

</details>

**题解**

**为什么 HF 话音常用 SSB**

**SSB** 是 **Single-Sideband Modulation（单边带调制）**。它只发送一个边带，能比普通 AM 更有效地利用带宽和发射功率，因此广泛用于 HF 话音通联。

业余无线电通常沿用以下操作习惯：

- 较低 HF 频段使用下边带（LSB）；
- 较高 HF 频段以及 VHF、UHF 使用上边带（USB）。

这是长期形成的通联约定，不是由传播规律强制决定的。

## 第 376 题

<span data-tts-skip><em>MC1-0437 · 单选 · 适用 A/B/C 类</em></span>

相比 SSB 方式，FM 的主要缺点是什么？

:::tip 正确答案
**无法同时守听多个信号**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 无法同时守听多个信号 ✓
- B. 抵抗脉冲干扰的能力差
- C. 对主载波的频率误差很敏感
- D. 含有恒定不变的载波分量，发射功率利用不充分

正确答案：A

</details>

**题解**

**FM 的捕获效应**

FM 具有恒包络、抗幅度噪声能力较好等优点，但同频出现多个信号时，接收机通常会被较强信号“捕获”，较弱信号受到压制，难以像较窄的 SSB 信号那样分别守听。

因此题目所说的主要缺点是：**无法同时守听多个信号**。
