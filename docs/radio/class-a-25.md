一部业余电台如何发起 CQ 呼叫？

:::tip 正确答案
**呼叫 CQ 并报出己方呼号。清晰起见，可重复一两次 CQ 并对呼号进行字母拼读**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 呼叫 CQ 并报出己方呼号。清晰起见，可重复一两次 CQ 并对呼号进行字母拼读 ✓
- B. 呼叫“有朋友在频率上吗？”，然后报出自己的呼号。清晰起见，可对呼号进行字母拼读
- C. 说“CQ”三次，再说“请过来”一次。清晰起见，可对 CQ 进行字母拼读
- D. 说“CQ”三次，再说“standing by”一次。清晰起见，可对 CQ 进行字母拼读

正确答案：A

</details>

**题解**

**发起 CQ 呼叫**

呼叫 **CQ** 后报出自己的呼号。为清晰起见，可以重复一两次 **CQ**，并用标准字母解释法拼读自己的呼号。

字母拼读针对呼号，不需要把 **CQ** 本身逐字拼读。

## 第 250 题

<span data-tts-skip><em>MC1-0263 · 单选 · 适用 A/B 类</em></span>

业余电台建立通信后，双方应首先交换的必要信息是：

:::tip 正确答案
**信号报告**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 信号报告 ✓
- B. 操作员名字
- C. 操作地点
- D. 设备、设施情况

正确答案：A

</details>

**题解**

**首先交换信号报告**

建立通信后，双方首先交换**信号报告**。常用 RST 系统包括：

- R（Readability）：可辨度；
- S（Strength）：信号强度；
- T（Tone）：音调。

话音通信通常使用 RS 两位报告，CW 使用 RST 三位报告。
