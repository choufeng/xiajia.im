## 第 552 题

<span data-tts-skip><em>MC1-0861 · 单选 · 适用 A/B/C 类</em></span>

接收机接收 SSB 话音信号时的频响均匀程度可以用选择性指标来表示，分别为：

:::tip 正确答案

:::

- B. 信道带宽、信道选择性和信道滤波器的矩形系数
- C. 镜像抑制比
- D. 前端带宽

正确答案：A

</details>

**题解**

**1. 相关知识点解释**
**选择性指标**是衡量接收机在复杂信号环境中区分目标信号与干扰信号能力的关键参数，主要包括以下内容：
- **带内波动**（In-band Ripple）：指接收机信道滤波器通带内信号幅度的变化范围，直接影响频响的平坦性。
- **信道带宽**（Channel Bandwidth）：滤波器允许通过的频率范围（如3 dB带宽），决定了信号的通频带宽度。
- **信道滤波器的矩形系数**（Shape Factor）：定义为滤波器60 dB带宽与3 dB带宽的比值，反映滤波器的陡峭程度。
- **镜像抑制比**（Image Rejection Ratio）：抑制镜像频率干扰的能力，与混频器设计和正交解调相关，但与频响均匀性无直接关联。
- **前端带宽**（Front-end Bandwidth）：射频前端的输入带宽，主要影响接收机的整体频率覆盖范围，而非局部频响平坦性。

**2. 解题思路与分析过程**
题目要求选择与**SSB话音信号频响均匀程度**直接相关的选择性指标。SSB信号的典型带宽为3 kHz（300 Hz至3400 Hz），对频响平坦性要求较高，需关注通带内的幅度一致性。

- **选项一**：带内波动和信道带宽  
  **带内波动**直接描述通带内幅度的均匀性，是频响平坦性的核心指标；**信道带宽**定义了通带范围，若带宽过宽或过窄可能导致频响不均。两者均与频响均匀性直接相关，符合题意。

- **选项二**：信道带宽、信道选择性和信道滤波器的矩形系数  
  - **信道选择性**（Channel Selectivity）指滤除邻道干扰的能力，通常通过邻道抑制比衡量，与频响均匀性无直接关系。  
  - **矩形系数**反映滤波器的频率选择性，影响邻近干扰的抑制，但对通带内的幅度波动无直接影响。  
  因此该选项中部分指标（如信道选择性）与题干无关。

- **选项三**：镜像抑制比  
  镜像抑制比用于抑制镜像频率干扰，属于混频器设计范畴，与频响均匀性无关。

- **选项四**：前端带宽  
  前端带宽决定接收机的整体频率覆盖范围，但频响均匀性主要由中频或基带滤波器特性决定，因此该指标不直接相关。

**3. 答案分析**
**正确答案**：**带内波动和信道带宽**  
- **带内波动**直接量化频响的均匀程度，是核心指标。  
- **信道带宽**定义通带范围，若带宽设计不合理（如过宽或过窄）会导致边缘频率响应下降，影响均匀性。  
其他选项中的信道选择性、矩形系数、镜像抑制比和前端带宽均与频响均匀性无直接关联。

**4. 知识库引用**
文档：**ITU 无线电规则（2024年版）卷2 ：附录**  
章节：**B部分 –单边带（SSB）系统 2.8 无用边带的衰减**  
引用内容：  
- 带内波动在“选择性指标”中被明确列为影响频响均匀性的因素。  
- 信道带宽与音频频段（300 Hz至3400 Hz）的设计要求直接相关，需匹配SSB信号带宽以确保平坦响应。

**题解**

**1. 相关知识点解释**
- **镜像抑制比（Image Rejection Ratio）**：  
  在超外差接收机中，当干扰信号的频率与本振频率相差两倍中频（即 $ f_{\text{干扰}} = f_{\text{本振}} \pm 2f_{\text{中频}} $）时，该干扰信号会与本振信号混频后生成与有用信号相同的中频频率，形成镜像频率干扰。镜像抑制比是接收机抑制此类干扰的能力指标，通常定义为有用信号与镜像干扰信号的幅度比值（单位：dB）。

- **其他干扰抑制指标**：  
  - **前端带宽**：主要影响接收机对宽带干扰的容忍度。  
  - **带内波动**：描述滤波器通带内增益的平坦性，与镜像干扰无直接关联。  
  - **信道选择性**和**矩形系数**：用于衡量接收机区分邻近信道信号的能力（如 $ \frac{60\,\text{dB带宽}}{3\,\text{dB带宽}} $），与镜像频率无关。

**2. 解题思路与分析过程**
1. **明确干扰类型**：  
   题干中干扰信号频率与工作频率相差两倍中频（即 $ \Delta f = 2f_{\text{中频}} $），这正是**镜像频率干扰**的典型特征。

2. **匹配指标与干扰类型**：  
   - **镜像抑制比**直接针对镜像频率干扰，是唯一能反映接收机对两倍中频干扰信号的抑制能力的指标。  
   - 其他选项（如信道选择性、矩形系数）均用于描述对邻近信道干扰的抑制，而非镜像干扰。

3. **排除干扰选项**：  
   - 前端带宽、带内波动等参数与镜像干扰无直接关联。  
   - 信道滤波器矩形系数仅影响邻近信道的区分能力。

**3. 答案分析**
- **正确答案**：  
  **镜像抑制比**  
  原因：镜像频率干扰直接由 $ f_{\text{干扰}} = f_{\text{工作}} \pm 2f_{\text{中频}} $ 产生，而镜像抑制比是唯一专门衡量接收机对此类干扰抑制能力的指标。

- **错误选项分析**：  
  - **前端带宽**：影响接收机整体抗干扰能力，但无法针对性抑制镜像频率。  
  - **带内波动和信道带宽**：描述滤波器通带特性，与镜像干扰无关。  
  - **信道带宽、信道选择性和矩形系数**：均用于邻近信道干扰抑制（如 $ \text{信道选择性} = \frac{\text{有用信号抑制比}}{\text{邻道干扰抑制比}} $），不适用于镜像干扰场景。

**题解**

**1. 知识点解释**
**信号强度刻度（S表）**：  
业余无线电接收机通过S表（S-meter）指示信号强度，通常以S1至S9划分刻度。S1代表最小可检测信号电平，其对应的功率电平因频段而异。  
**背景噪声**：  
接收机在特定频段接收到的噪声包括大气噪声（如闪电）、工业噪声（如电器干扰）和接收机内部热噪声。HF频段（3-30 MHz）受大气噪声和工业噪声影响显著，而VHF/UHF（30-3000 MHz）频段的噪声主要来自接收机内部热噪声。  
**信号功率与电压关系**：  
在50Ω阻抗系统中，功率（P）与电压（V）满足公式：  
$$
P = \frac{V^2}{R} \quad \Rightarrow \quad V = \sqrt{P \cdot R}
$$  
因此，-141 dBm（0.02 μV）和-121 dBm（0.2 μV）的差异对应约20 dB的功率差。

**2. 解题思路**
**问题核心**：

1. **背景噪声差异**：  
   HF频段（3-30 MHz）受大气噪声（如雷电）和工业噪声影响较大，整体背景噪声功率显著高于VHF/UHF频段。  
2. **最小可感知信号（MDS）**：  
   接收机的MDS需高于背景噪声才能被有效检测。HF频段的背景噪声功率比VHF/UHF高约20 dB，因此HF接收机的S1刻度需对应更高的输入功率（-121 dBm）。  
3. **排除其他选项**：  
   - **选项2**（技术原因导致HF灵敏度低）：无直接技术限制，现代接收机设计可优化灵敏度，但噪声环境无法改变。  
   - **选项3**（发射功率差异）：S表是接收机特性，与发射功率无关。  
   - **选项4**（通信目的差异）：刻度标准基于物理规律，而非通信需求。  

**3. 答案分析**
**正确答案**：  
**HF频段的背景噪声较VHF/UHF频段为高，使得可感知最小信号电平相应高出约20dB**  

**其他选项分析**：  
- **选项2**：HF接收机的灵敏度可通过技术优化，但背景噪声的物理限制是主要因素。  
- **选项3**：发射功率影响信号传播距离，但与接收机S表刻度无关。  
- **选项4**：S表刻度是标准化的国际规范（参考ITU-R建议书），而非随意设定。  

**知识库引用**：  
- 《ITU 无线电规则（2024年版）卷2 ：附录》提及接收机噪声限制灵敏度（3.1节）和调制处理要求，间接支持噪声环境对信号检测的影响。  
- 《中华人民共和国无线电频率划分规定》定义了不同频段的噪声特性，HF频段受噪声影响显著。  

**4. 结论**
HF频段S1刻度对应的功率电平更高，根本原因是其背景噪声较VHF/UHF频段高约20 dB。这一差异反映了接收机设计需适应不同频段的电磁环境，而非单纯依赖技术或通信需求。

**题解分析**

本题考查的是业余无线电收发信机**接收机灵敏度（sensitivity）**相关概念的理解。  

**一、相关知识点解析**

1. **接收机灵敏度的定义**  
   接收机灵敏度通常定义为在规定的信噪比（S/N）、或误码率（BER），或者特定的音频输出质量条件下，接收机能够可靠接收的最小输入信号电压（通常单位为 μV）。  
   - 灵敏度数值越小，表示接收机能在更微弱的输入电平下正常工作，**灵敏度更高**。  
   - 但前提是，两个灵敏度指标的测试条件必须一致（如 20dB S/N、12dB SINAD 等）。如果测试条件不统一，灵敏度值本身没有可比性。

2. **本题设定**  
   - 甲机接收灵敏度：0.1 μV  
   - 乙机接收灵敏度：0.15 μV  
   表面看，0.1 μV < 0.15 μV，说明甲机可以接收更弱的信号 → 灵敏度较高。  
   但是题目问的是"关于该指标，正确的推论"，需要结合灵敏度的定义与限制进行分析。

**二、逐项分析各选项**

1. **“无法比较二者接收微弱信号的能力，测量灵敏度时所用的输出信号质量标准未知”**  
   - 灵敏度的数值比较必须在**相同的测量条件**下才有意义。如果不知道厂商采用的测试标准（比如是以 20dB SINAD，还是“可辨识语音”的条件来测量），两个数值没有绝对可比性。  
   - 本选项从理论上是正确的科学态度：如果标准不明，就不能直接比较。  
   - 本题的考点就在于考生是否理解**灵敏度数值的比较前提条件**，所以该选项正确。

2. **“可以推断甲机接收微弱信号的能力比乙机的差，因为灵敏度指标的数值较小”**  
   - 实际上，灵敏度指标**数值越小越好**。  
   - 0.1 μV 对比 0.15 μV，前者代表接收机可以解调更弱的信号。  
   - 该选项错误地认为“数值小 = 性能差”，正好与事实相反，因此错误。

3. **“可以推断甲机接收微弱信号的能力比乙机的高，因为可以接收的信号更微弱”**  
   - 按照灵敏度的物理意义，这句话正确：0.1 μV < 0.15 μV，说明甲机确实更灵敏。  
   - 但是！前提是 **双方采用的测试条件必须相同**。题目只给出了两个数值，未说明测试条件是否一致 → 理论上不能直接下此结论。  
   - 因此，这个选项带有常识性的推断，但是严格来说未必正确。考试中会扣题干的严谨条件，一般不选。

4. **“可以推断甲机承受强信号的能力比乙机的低，因为其灵敏度数值比较小”**  
   - 灵敏度和接收机的**强信号处理能力（如动态范围、互调抑制、镜像抑制等指标）**是完全不同的性能参数。  
   - 灵敏度高并不意味着强信号下性能差；强信号能力需要靠前端电路设计和抗干扰能力指标来判断。  
   - 因此，该选项混淆了两个独立概念，错误。

**三、正确答案与解题思路**

- 从严格考试的角度，本题的正确选项是：  
  **“无法比较二者接收微弱信号的能力，测量灵敏度时所用的输出信号质量标准未知”**

- 解题思路：  
  1. 理解灵敏度的定义——最小输入可用信号电平  
  2. 明确“数值越小越灵敏”的基本常识  
  3. 考虑测量条件的重要性 → 若未知，就不能贸然比较  
  4. 排除混淆灵敏度和强信号处理能力的选项

**四、知识点总结**

- **灵敏度：数值越小越好，但必须基于相同测试条件才能比较。**  
- **灵敏度 ≠ 抗强信号能力**，这是两个完全不同的技术指标。  
- 考试时遇到类似题目，要优先考虑测试条件是否统一，否则不能直接下性能高低的结论。  
- 正确的思路是：先判断题干是否给出了统一的测量标准 → 没给出则不能比较。
