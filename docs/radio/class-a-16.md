擅自编制、使用业余无线电台呼号，无线电管理机构可以根据其具体情况给予下列处罚：

**由无线电管理机构责令改正，没收违法所得，可以并处 3 万元以下的罚款**<span data-tts-skip>（A）</span> · **造成严重后果的，吊销无线电台执照，并处 3 万元以上 10 万元以下的罚款**<span data-tts-skip>（B）</span>

- D. 责令停止使用非法设置的电台并作出书面检查；情节严重的，可以并处一千元以下的罚款

**题解**

****知识点解释****
根据《中华人民共和国无线电管理条例》第八章第七十二条第三项，擅自编制、使用无线电台识别码（包括业余无线电台呼号）属于违法行为。  
- **核心依据**：《中华人民共和国无线电管理条例》第七十二条  
  - 一般情形：责令改正，没收违法所得，可并处**3万元以下罚款**。  
  - 严重后果：吊销无线电台执照，并处**3万至10万元罚款**。

****解题思路与分析过程****
1. **定位法律依据**：  
   - 题目涉及违法行为的处罚措施，需结合《无线电管理条例》第七十二条第三项。  
   - 该条款明确将“擅自编制、使用无线电台识别码”纳入处罚范围。  

2. **逐项分析选项**：  
   - **选项1**（责令改正，没收违法所得，可并处3万元以下罚款）：  
     符合第七十二条第一档处罚，正确。  
   - **选项2**（造成严重后果的，吊销执照，并处3万至10万元罚款）：  
     符合第七条第二档处罚，正确。  
   - **选项3**（责令停止使用非法电台，情节严重时查封或没收设备）：  
     对应《条例》第七十条（未经许可设置电台的处罚），与本题无关，错误。  
   - **选项4**（责令停止使用并书面检查，情节严重时罚款千元以下）：  
     处罚力度明显低于法规规定，且无直接法律依据，错误。  

3. **结论**：  
   仅前两项处罚措施与《无线电管理条例》第七十二条完全一致，其余选项为干扰项。

****答案分析****
- **正确答案**：  
  - **责令改正，没收违法所得，可以并处3万元以下的罚款**  
  - **造成严重后果的，吊销无线电台执照，并处3万元以上10万元以下的罚款**  
- **错误选项原因**：  
  - 选项3和4的处罚措施未引用《无线电管理条例》第七十二条，而是混淆了其他条款（如第七十条），或与法规规定的罚款金额不符。  

****引用文档****
- **《中华人民共和国无线电管理条例》第七十二条**  
  > 违反本条例规定，有下列行为之一的，由无线电管理机构责令改正，没收违法所得，可以并处3万元以下的罚款；造成严重后果的，吊销无线电台执照，并处3万元以上10万元以下的罚款：（三）擅自编制、使用无线电台识别码。  

****总结****
本题考查对擅自编制、使用业余无线电台呼号处罚措施的掌握，需精准区分不同违法行为对应的法律条款。答题时应直接引用《无线电管理条例》第七十二条，排除混淆选项。
