## 第 643 题

<span data-tts-skip><em>MC1-0973 · 单选 · 适用 A/B/C 类</em></span>

有些收发信机会在直流 13.8V 供电线路中串联一个熔断器，并在其后反向并联一个额定电流很大的二极管作保护之用。该电路利用了二极管的什么特性？是如何工作的？

:::tip 正确答案
**利用二极管中 PN 结的单向导电性；若电源极性接反，近乎短路的电流烧断熔丝，切断供电**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 利用二极管中 PN 结的单向导电性；若电源极性接反，近乎短路的电流烧断熔丝，切断供电 ✓
- B. 在电源过压时利用二极管的击穿特性吸收电流以稳定供电电压
- C. 在电源过流时利用二极管的击穿特性吸收电流以稳定供电电压
- D. 若设备过热时利用二极管的热失控特性短路电源，烧断熔丝，切断供电

正确答案：A

</details>

**题解**

**1. **知识点解释****
二极管的核心特性是 **PN 结的单向导电性**：  
- **正向导通**：当阳极（P区）接高电位、阴极（N区）接低电位时，二极管导通，呈现低阻抗。  
- **反向截止**：当阳极接低电位、阴极接高电位时，二极管截止，呈现高阻抗。  
- **击穿特性**：当反向电压超过击穿电压时，二极管反向导通，但电压基本保持恒定（如稳压二极管）。  
- **热失控**：部分半导体器件在高温下电流急剧增加的现象，但并非二极管的核心保护特性。

**2. **解题思路与分析过程****
题目中电路的核心设计是 **电源极性反接保护**：  
- **熔断器**：用于过流保护，当电流超过额定值时熔断，切断电路。  
- **反向并联二极管**：其阴极接电源正极，阳极接电源负极（与正常供电方向相反）。  

**工作原理**：  
- **正常供电**：二极管处于反向截止状态，电路正常工作。  
- **电源极性反接**：二极管变为正向导通，形成低阻抗通路，电流急剧增大，远超熔断器额定值，导致熔断器迅速熔断，切断供电。  

**3. **答案分析****
- **正确选项**：**利用二极管中 PN 结的单向导电性；若电源极性接反，近乎短路的电流烧断熔丝，切断供电**  
  - 二极管的单向导电性是核心特性。  
  - 电源极性反接时，二极管正向导通，相当于短路，触发熔断器动作。  

- **错误选项排除**：  
  - **过压保护**：需利用二极管的击穿特性（如稳压二极管），但题目未提及过压场景。  
  - **过流保护**：熔断器本身已具备过流保护功能，二极管并非“吸收电流”的主体。  
  - **热失控特性**：非二极管的典型保护机制，且题目未涉及设备过热场景。  

**4. **结论****
该电路通过二极管的单向导电性实现电源极性反接保护。当电源极性接反时，二极管正向导通形成短路电流，熔断熔丝以切断供电，避免设备损坏。  

**答案**：  
**利用二极管中 PN 结的单向导电性；若电源极性接反，近乎短路的电流烧断熔丝，切断供电**

<span data-tts-skip><em>MC1-1298 · 单选 · 适用 A/B/C 类</em></span>

用万用表的直流电压档测量正负对称的方波电压（占空比为 1:1）。所得读数为：

:::tip 正确答案
**零值**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 零值 ✓
- B. 该电压的最大值
- C. 该电压最大值的 1/2
- D. 该电压最大值的 2 倍

正确答案：A

</details>

**题解**

直流电压档反映信号的直流分量，也就是一个周期的平均值。正、负对称且占空比为 1:1 的方波，正负面积恰好抵消：

$$\overline{V}=0$$

所以直流档读数为零。

## 第 646 题

<span data-tts-skip><em>MC1-1299 · 单选 · 适用 A/B/C 类</em></span>

如果用磁电式万用表的交流电压档测量正负对称的方波电压（占空比为 1:1），其指针所示的电压读数：

:::tip 正确答案
**大于该电压的峰值**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 大于该电压的峰值 ✓
- B. 为该电压的峰值
- C. 为该电压的峰-峰值
- D. 为该电压的平均值

正确答案：A

</details>

**题解**

大多数普通磁电式万用表的交流档首先会将交流电通过二极管、全桥等电路转换为脉冲直流电，然后再通过 RC/LC 网络对脉冲直流电滤波转换为恒定的直流电驱动表头实现读数和测量。

由于一般情况下 RC/LC 网络是按照 $50Hz$ 正弦波交流电标定设计的，所以使用其他频率的交流电或者其他波形的交流电（可以看作是多个不同频率正弦交流电的叠加）会导致 RC/LC 网络输出的电压值和真实的有效值不等。

考虑到 RC/LC 网络是在消耗能量实现削峰填谷的目的，对于方波的波形，实际上是不需要消耗能量削峰填谷的，因此不需要额外消耗本该消耗的能量。按照这种定性的分析，可以推测电压读数会比真实的有效值更大。（笔者更建议大家用万用表实测一下）

## 第 647 题

<span data-tts-skip><em>MC1-1300 · 单选 · 适用 A/B/C 类</em></span>

用指针式万用表的直流电压档测量最小值为 0 的方波电压（占空比为 1:1），得到的读数是该电压的：

:::tip 正确答案
**峰值的 1/2，亦为有效值**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 峰值的 1/2，亦为有效值 ✓
- B. 零值
- C. 峰值
- D. 峰-峰值

正确答案：A

</details>

**题解**

设方波在 0 与峰值 $V_p$ 之间变化，占空比为 1:1。指针式万用表的直流电压档反映其平均值，因此读数为：

$$
\overline{V}=\frac{V_p}{2}
$$

需要注意，整个方波的有效值为 $V_p/\sqrt{2}$，并不是 $V_p/2$；所以题目选项中的“亦为有效值”在严格意义上并不准确。

用万用表的电阻档测量一个电路。最开始，电表指示电路的阻值很小。但是随着测量时间的延长，测量值却变得越来越大。这是因为：

:::tip 正确答案
**这个电路两端可能存在一个很大的电容**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 这个电路两端可能存在一个很大的电容 ✓
- B. 万用表出了故障
- C. 这个电路两端可能存在一个很大的电感
- D. 这个电路中存在一个周期性的交流电压

正确答案：A

</details>

**题解**

万用表电阻档会向被测电路施加直流测试电压。若两端存在大电容：

- 刚接入时电容尚未充电，充电电流较大，表观电阻很小；
- 随着电容充电，电流逐渐减小，表观电阻不断增大；
- 最后趋向由漏电决定的高阻值。

这正是读数随时间由小变大的原因。

## 第 650 题

<span data-tts-skip><em>MC1-1303 · 单选 · 适用 A/B/C 类</em></span>

用指针式万用电表的电阻档测量一个常用元件，表笔第一次连接时表针挥动了一下，但很快回到零点。断开表笔重新连接，表针却不再有任何指示。正确的推论是：

:::tip 正确答案
**该元件可能是一个电解电容器**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 该元件可能是一个电解电容器 ✓
- B. 该元件肯定是一支损坏了的电阻
- C. 万用表的准确度肯定有问题
- D. 万用表的电池肯定电量不足了

正确答案：A

</details>

**题解**

**1. 相关知识点解释**
指针式万用表的电阻档通过内部电池供电，在测量时形成回路电流，表针偏转角度与电流大小成正比。  
- **电解电容器**：具有极性，且存在充放电特性。当首次测量时，电容充电导致瞬时电流，表针偏转；充电完成后电流消失，表针回到零点。重新连接时若极性反向或电容未放电，可能因无电流或击穿现象导致无指示。  
- **损坏的电阻**：若电阻开路（断路），测量时无电流通过，表针始终无指示。  
- **万用表电池电量不足**：通常表现为无法调零或测量时偏转角度异常（如始终无法归零），但首次测量仍可能有短暂反应。  

**2. 解题思路与分析过程**
1. **首次测量现象**：表针挥动后回到零点  
   - 表明元件在短时间内存在电流，但随后电流消失。  
   - 符合电容充电过程（充电时电流逐渐衰减至零）。  

2. **重新连接后无指示**：  
   - 若元件为电解电容，可能因首次充电后已充满（无剩余电荷），或反向连接导致击穿（但题目未明确极性）。  
   - 若元件为电阻开路，首次测量应无反应，与现象矛盾。  
   - 万用表电池问题通常导致持续性测量异常（如调零失败），而非单次测量异常。  

3. **排除其他选项**：  
   - 损坏的电阻无法解释首次偏转；  
   - 万用表准确度或电池问题无法同时满足首次偏转和后续无指示的矛盾现象。  

**3. 答案分析**
**该元件可能是一个电解电容器**：  
- 符合首次测量时电容充电导致表针偏转并逐渐归零的现象；  
- 重新连接后无指示可能是电容已充满或极性反向导致无电流通过；  
- 其他选项与现象矛盾（如损坏的电阻不会首次偏转，电池不足不会导致特定单次现象）。  

**4. 其他选项错误原因**
- **损坏的电阻**：电阻开路时首次测量无电流，表针无偏转，与题干矛盾。  
- **万用表准确度问题**：若存在故障，两次测量均应出现异常（如指针卡滞或固定偏移），而非单次有效测量。  
- **万用表电池电量不足**：电池不足时，电阻档通常无法调零，且测量时表针偏转幅度会显著降低，但首次偏转后归零的现象更符合电容特性。  

**最终答案**：该元件可能是一个电解电容器。

<span data-tts-skip><sub>—— 题解：通义千问（经精简整理）</sub></span>
