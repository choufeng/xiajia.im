<span data-tts-skip><em>MC1-0422 · 单选 · 适用 A/B/C 类</em></span>

在业余无线电通联中探讨天线时，缩写 LW 代表：

:::tip 正确答案
**长线天线**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 长线天线 ✓
- B. 偶极天线
- C. 定向天线
- D. 垂直天线

正确答案：A

</details>

**题解**

**1. 相关知识点解释**
在业余无线电领域，天线类型的缩写通常与英文名称直接相关：
- **长线天线（Long Wire Antenna）**：由单根较长的导线构成，长度通常为工作波长的1/2或更长，常用于HF频段。
- **偶极天线（Dipole Antenna）**：由中心馈电的对称双导体结构构成，长度一般为半波长。
- **定向天线（Directional Antenna）**：如八木天线（Yagi-Uda），具有明显的方向性增益。
- **垂直天线（Vertical Antenna）**：单极子结构，通常与地面垂直，辐射方向图全向。

**2. 解题思路与分析过程**
题目要求判断缩写"LW"对应的天线类型。根据国际通用的无线电术语：
- **LW** 是 **Long Wire** 的缩写，直译为“长线”，专指长线天线。
- 其他选项的常见缩写分别为：
  - 偶极天线（Dipole）→ **DP**
  - 定向天线（Directional）→ **DIR** 或 **YAGI**
  - 垂直天线（Vertical）→ **VERT**

通过排除法可确认：
1. **长线天线**唯一对应"LW"；
2. 其他选项的缩写与"LW"无直接关联。

**3. 答案分析**
**正确答案：长线天线**

**错误选项辨析**：
- **偶极天线**：英文"Dipole"缩写为**DP**，与"LW"无关。
- **定向天线**：方向性是天线特性而非特指某类型，常用缩写为**DIR**或具体类型（如YAGI）。
- **垂直天线**：英文"Vertical"缩写为**VERT**，与"LW"无关联。

**题解**

参考 ITU 的 [分类方案](https://www.itu.int/en/ITU-R/terrestrial/workshops/wrs12/Miscellaneous/Appendix1.pdf) 以及 [《中华人民共和国无线电频率划分规定》](https://wap.miit.gov.cn/gyhxxhb/jgsj/cyzcyfgs/bmgz/wxdl/art/2023/art_1e98823e689f42ca9ed14dcb6feec07a.html) 附录三

对于 CW 而言：

* CW 通过电键控制是否输出载波。由于载波是双边带的正弦波，所以应当是双边带幅度调制（A）
* CW 发报就是单一信道的通信，通过电键的开关产生数字信息，不需要任何副载波（1）
* CW 是人工收发的电报（A）

因此 CW 的分类为 A1A

| K | 幅度调制的脉冲序列 | **K**een amplitude |
| L | 宽度/持续时间调制的脉冲序列 | **L**ength |
| M | 位置/相位调制的脉冲序列 | **M**ove position |

其他的一些助记方法：

**常用组合记忆**

1. **广播业务常用组合**：
   - F3E = FM广播：FM(**F**)用模拟(**3**)传声音(**E**)
   - A3E = AM广播：AM(**A**)用模拟(**3**)传声音(**E**)
   - J3E = SSB语音通信：抑制载波(**J**)用模拟(**3**)传声音(**E**)

2. **数字通信常用组合**：
   - F1D = 数字FM：FM(**F**)单通道数字(**1**)传数据(**D**)
   - F2D = 使用副载波的数字FM：FM(**F**)带副载波(**2**)传数据(**D**)

**记忆规律**

1. **字母顺序关联**：
   - F和G相邻（频率调制和相位调制）
   - A到J的幅度调制系列

2. **数字规律**：
   - 0-3：单通道系列
   - 7-9：多通道系列

3. **分组记忆**：
   - 幅度调制组：A, H, R, J, B, C

   - 收听广播→A3E或F3E

<span data-tts-skip><em>MC1-0431 · 单选 · 适用 A/B/C 类</em></span>

带外发射是指：

:::tip 正确答案
**由于调制过程而产生的、刚超出必要带宽的一个或多个频率的发射，但杂散发射除外**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 由于调制过程而产生的、刚超出必要带宽的一个或多个频率的发射，但杂散发射除外 ✓
- B. 由于调制过程而产生的、刚超出占用带宽的一个或多个频率的发射，但杂散发射除外
- C. 由于调制过程而产生的、刚超出参考带宽的一个或多个频率的发射，但杂散发射除外
- D. 由于调制过程而产生的、刚超出固定带宽的一个或多个频率的发射，但杂散发射除外

正确答案：A

</details>

**题解**

****1. 相关知识点解释****
- **带外发射（Out-of-band Emission）**  
  指由调制过程产生的、**刚超出必要带宽**的一个或多个频率的发射，但**不包括杂散发射**。  
  - **必要带宽（Necessary Bandwidth）**：指传输特定类型信号所需的最小带宽，通常由通信标准或协议决定。  
  - **杂散发射（Spurious Emission）**：指必要带宽之外的更远频率上出现的发射，例如谐波、寄生振荡等，通常与调制过程无关。  

****2. 解题思路与分析****
题目要求判断带外发射的正确定义，关键在于以下几点：  
1. **核心条件**：必须由**调制过程产生**，且**刚超出必要带宽**（而非其他带宽类型）。  
2. **排除条件**：必须**排除杂散发射**。  
3. **选项对比**：  
   - 选项1：正确描述了“必要带宽”。  
   - 选项2、3、4：错误地将“必要带宽”替换为“占用带宽”“参考带宽”“固定带宽”，这些术语在标准定义中并未提及。

****3. 答案分析****
- **正确选项**：  
  **由于调制过程而产生的、刚超出必要带宽的一个或多个频率的发射，但杂散发射除外**  
  - 引用依据：  
    - 《ITU 无线电规则（2024年版）卷1：条款》第1.144条：明确指出带外发射的定义。  
    - 《中华人民共和国无线电频率划分规定》第1.6.8条：与ITU定义一致。  

- **错误选项分析**：  
  - **占用带宽**：指信号实际占用的带宽，可能大于或等于必要带宽，但并非定义中的基准（见《中华人民共和国无线电频率划分规定》附录1）。  
  - **参考带宽/固定带宽**：非标准术语，未在任何权威文件中作为带外发射的判定依据。  

****4. 结论****
带外发射的定义严格基于**必要带宽**，这是国际和国内无线电管理规则中的统一标准。其他选项中的“占用带宽”“参考带宽”“固定带宽”均为干扰项，需结合标准文件排除。
