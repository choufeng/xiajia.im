<span data-tts-skip><em>MC1-0516 · 单选 · 适用 A/B/C 类</em></span>

使用 DRM 协议进行数字慢扫描电视（DSSTV）通信时，爱好者总是倾向于通过单边带而非调频话方式来传输在音频范围内生成的 DSSTV 基带。主要原因是：

:::tip 正确答案
**单边带方式完整保留 DSSTV 的基带特性，利于衰落信道中的差错控制**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 单边带方式完整保留 DSSTV 的基带特性，利于衰落信道中的差错控制 ✓
- B. 使用调频话传输 DSSTV 增添门限效应，因此也增加了信号的发射带宽
- C. 使用调频话传输 DSSTV 虽然可以改善画质，但是无法提高伴音的音质
- D. 使用调频话传输 DSSTV 虽然可以改善伴音的音质，但是无法提高画质

正确答案：A

</details>

**题解**

**1. **知识点解释****
- **DRM协议**：一种数字广播标准，主要用于短波（HF）和调幅（AM）频段，支持音频和数据的高效传输。  
- **DSSTV（数字慢扫描电视）**：业余无线电中用于传输低速数字图像的协议，需通过音频基带信号调制到射频载波上。  
- **单边带（SSB）调制**：仅传输一个边带，抑制载波和另一侧边带，频谱效率高，适合窄带通信。  
- **调频话（FM）调制**：通过载波频率偏移传递信息，抗干扰能力强但带宽较宽，存在“门限效应”（当信号强度低于某一阈值时，解调质量骤降）。  
- **衰落信道**：短波通信中常见的多径传播导致的信号幅度随机变化现象，需差错控制机制（如前向纠错FEC）提升可靠性。  

**2. **解题思路****
1. **分析DSSTV信号特性**：  
   DSSTV的基带信号需在音频范围内（通常300 Hz~3 kHz），调制后需保留其完整性以确保图像解码正确。  
2. **比较SSB与FM的特性**：  
   - **SSB优势**：频谱效率高（带宽约3 kHz），无门限效应，基带信号线性保真度高，适合结合FEC对抗衰落信道。  
   - **FM劣势**：带宽宽（通常16 kHz），存在门限效应，且调频过程会破坏基带信号的线性特性，导致数字信号解码困难。  
3. **结合选项分析**：  
   - **第一选项**：SSB保留基带特性，利于衰落信道的差错控制（如FEC）——符合DSSTV需求。  
   - **第二选项**：FM的门限效应和带宽增加是事实，但非“主要原因”，题目强调“保留基带特性”与数字通信的兼容性。  
   - **第三、四选项**：DSSTV主要关注图像传输，伴音质量非核心问题，且FM无法提升画质。  

**3. **答案分析****
**正确答案**：  
**单边带方式完整保留 DSSTV 的基带特性，利于衰落信道中的差错控制**  

**理由**：  
- **SSB保留基带特性**：数字慢扫描电视（DSSTV）依赖精确的基带信号解码图像，SSB的线性调制特性确保信号完整性，而FM的非线性调制会引入失真，破坏图像解码所需的数字结构（参考《ITU 无线电规则（2024年版）卷2》附录B部分关于SSB调制的音频频段要求）。  
- **门限效应与差错控制**：FM的门限效应在短波衰落信道中可能导致信号突发中断，而SSB无此问题，且可结合FEC（如DRM协议中的前向纠错）提升抗干扰能力。  
- **频谱效率**：SSB的窄带特性（通常<3 kHz）与DRM协议的带宽需求匹配，而FM的宽带占用（如16 kHz）浪费频率资源。  

**4. **知识库引用****
- **《ITU 无线电规则（2024年版）卷2》附录B部分**：  
  - 规定SSB的音频频段范围为350 Hz~2 700 Hz（抑制低频和高频分量），确保基带信号完整性。  
  - 强调SSB的窄带特性（必要带宽≤4.5 kHz）与数字调制的兼容性（如正交频分复用OFDM）。  

**5. **总结****
**单边带调制**因保留基带特性、抗衰落能力强和频谱效率高，成为DSSTV通信的首选；而**调频话**的门限效应、带宽占用及破坏数字信号完整性，导致其不适用于此场景。

:::tip 正确答案
**减小发信时电源线上的压降**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 减小发信时电源线上的压降 ✓
- B. 分流机箱外表面的射频电流
- C. 防止收发信机意外滑落摔坏
- D. 厂商销售电源线的一种策略

正确答案：A

</details>

**题解**

**为什么要短而粗**

## 第 396 题

<span data-tts-skip><em>MC1-0569 · 单选 · 适用 A 类</em></span>

单工操作（simplex operation）是指：在一条电信通路的两个方向上交替进行传输的一种工作方式。下列通信采用单工操作方式：

:::tip 正确答案
**两台由 PTT 键转换收发状态的业余对讲机之间的通信**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 两台由 PTT 键转换收发状态的业余对讲机之间的通信 ✓
- B. 两台有线电话座机之间的通信
- C. 两台公众移动电话终端（手机）之间的通信
- D. 一台业余中继台与一台由 PTT 键转换收发状态的业余对讲机之间的通信

正确答案：A

</details>

**题解**

****1. 知识点解释****
单工操作（simplex operation）的定义是：**在一条电信通路的两个方向上交替进行传输**（参见《中华人民共和国无线电频率划分规定》1.5.10条）。这意味着通信双方无法同时发送和接收信号，必须通过人工或自动控制切换收发状态。  
常见应用场景包括：  
- **对讲机（PTT键控）**：按住PTT键发送，松开后接收。  
- **广播通信**：单向传输（如调频广播）。  

****2. 解题思路****
题目要求判断哪些通信方式符合单工操作的定义。需逐一分析选项的通信机制是否满足“**双向交替传输**”的核心条件。

****3. 答案分析****

1. **两台由PTT键转换收发状态的业余对讲机之间的通信**  
   - **正确**。  
   - **分析**：PTT键（Push-To-Talk）的设计决定了通信双方需手动切换收发状态。一方按住PTT键发送时，另一方只能接收；松开后才能接收信号。这种“交替传输”完全符合单工操作的定义。  
   - **参考依据**：《中华人民共和国无线电频率划分规定》1.5.10条（单工操作定义）。

2. **两台有线电话座机之间的通信**  
   - **错误**。  
   - **分析**：有线电话采用全双工（full-duplex）技术，双方可同时发送和接收语音信号（例如，通话时可同时听到对方声音并发言），不符合“交替传输”的要求。

3. **两台公众移动电话终端（手机）之间的通信**  
   - **错误**。  
   - **分析**：手机通信基于蜂窝网络，通常使用全双工或半双工技术（如TDD时分双工），允许双方同时或快速切换收发状态，不满足单工操作的定义。

4. **一台业余中继台与一台由PTT键转换收发状态的业余对讲机之间的通信**  
   - **错误**。  
   - **分析**：中继台的作用是接收信号并转发到另一频率。对讲机通过PTT键发送信号到中继台（单向），但中继台会持续转发信号（双向同时），因此通信路径中存在同时双向传输，属于**半双工或双工操作**，而非单工。

****4. 结论****
**正确答案**：两台由PTT键转换收发状态的业余对讲机之间的通信。  
**核心依据**：单工操作要求通信双方在一条通路上交替传输，而PTT键控对讲机的机制完全符合此定义。其他选项均涉及全双工或半双工通信，不符合交替传输的特征。

**引用文档**：  
《中华人民共和国无线电频率划分规定》1.5.10条（单工操作定义）。

双工操作（duplex operation）是指：一条电信通路的两个方向能同时进行传输的工作方式。下列通信采用双工操作方式：

:::tip 正确答案
**由一台连续工作的 430MHz 接收机和一台 144MHz 发信机组成的地面业余电台与业余卫星之间的通信**<span data-tts-skip>（A）</span>
:::

<details>
<summary>查看全部选项</summary>

- A. 由一台连续工作的 430MHz 接收机和一台 144MHz 发信机组成的地面业余电台与业余卫星之间的通信 ✓
- B. 两台具有 QSK 功能的业余 CW 收发信之间的通信
- C. 一台业余中继台与一台由 PTT 键转换收发状态的业余对讲机之间的通信
- D. 两台由 PTT 键转换收发状态的业余对讲机之间的通信

正确答案：A

</details>

**题解**

题解内容已参照用户 itsuki 建议进行修订。

**1. 相关知识点解释**
**双工操作**的定义是：一条电信通路的两个方向能**同时**进行传输的工作方式。  
- **全双工**（Full-duplex）：双方可同时收发信号（如电话通信）。  
- **半双工**（Half-duplex）：双方可交替收发信号，但不能同时（如对讲机）。  

由于题目为单选题，这里暂且认为题目中的“双工操作”是指“全双工”。

**2. 解题思路与分析**
逐一分析选项：  

1. **地面业余电台与业余卫星通信**  
   - 地面站使用**430MHz接收机**和**144MHz发信机**，分别用于接收卫星下行信号（430MHz）和发送上行信号（144MHz）。  
   - **关键点**：接收机和发信机**同时工作**，且频率不同（跨频段操作），符合双工定义。  

2. **两台具有QSK功能的CW收发信机通信**  
   - QSK功能允许在发送间隙实时监听对方信号（即“快速收发转换”），但**收发不同时进行**（交替切换），属于**半双工**。  

3. **中继台与PTT对讲机通信**  
   - 中继台需同时接收上行信号（如144MHz）并转发下行信号（如430MHz），属于**全双工操作**。  
   - 对讲机通过PTT键切换收发状态（半双工），整体来看，并结合该题为单选题考虑，实际上还是处于“半双工操作”。  

4. **两台PTT对讲机通信**  
   - PTT键控制收发切换（按住发送、松开接收），双方**不能同时传输**，属于**半双工**。

**3. 答案分析**
**正确答案**：  
- **由一台连续工作的 430MHz 接收机和一台 144MHz 发信机组成的地面业余电台与业余卫星之间的通信**  

**错误选项**：  
- **两台具有 QSK 功能的业余 CW 收发信之间的通信**：QSK为半双工，未实现同时收发。  
- **一台业余中继台与一台由 PTT 键转换收发状态的业余对讲机之间的通信** ：整体看属于半双工。
- **两台由 PTT 键转换收发状态的业余对讲机之间的通信**：PTT键切换收发，属于半双工。

**选择依据**：  
- 双工操作的核心是**两个方向能同时传输**。  
- 卫星通信和中继台操作均通过**不同频率**实现同时收发，符合双工定义。  

**引用知识库**：  
- 《No-Nonsense Technician Class License Study Guide》指出，中继器操作称为双工操作（Duplex Operation），因其使用不同频率收发。  
- ITU 无线电规则定义双工操作为“两个方向能同时传输”（1.126款）。  

**4. 结论**
**双工操作的关键是“同时收发”且“方向独立”**：  
- 卫星通信（跨频段同时收发）符合要求。  
- 半双工（QSK、PTT）仅支持交替收发，不符合定义。

半双工操作（semi-duplex operation）是指：电路的一端用单工操作，另一端用双工操作的一种工作方式。下列通信采用半双工操作方式：

:::

<details>
<summary>查看全部选项</summary>

- A. 一台业余中继台与一台由 PTT 键转换收发状态的业余对讲机之间的通信 ✓
- B. 两台具有 QSK 功能的业余 CW 收发信之间的通信
- C. 两台由 PTT 键转换收发状态的业余对讲机之间的通信
- D. 两台公众移动电话终端（手机）之间的通信

正确答案：A

</details>

**题解**

**1. 知识点解释**
**半双工操作（Semi-duplex operation）**：根据《中华人民共和国无线电频率划分规定》第1.5.12条的定义，半双工操作是指电路的一端采用单工操作（仅单向传输），另一端采用双工操作（双向同时传输）的工作方式。这种模式允许通信双方交替收发信号，但不能完全同时进行双向通信。

**2. 解题思路**
题目要求判断哪种通信方式符合半双工操作。需逐一分析选项：  
1. **业余中继台与PTT对讲机**：  
   - 中继台需同时接收和转发信号（双工操作）。  
   - 对讲机通过PTT键切换收发状态（单工操作）。  
   - 符合“一端单工，另一端双工”的定义。  

2. **QSK功能的CW收发信机**：  
   - QSK功能允许在发报间隙接收信号，属于**全双工**（或类似特性），不满足半双工的条件。  

3. **两台PTT对讲机**：  
   - 双方均通过PTT切换收发，均为单工操作，属于**单工通信**，非半双工。  

4. **手机通信**：  
   - 手机通常采用**全双工**（如FDD模式），可同时收发信号。  

**3. 答案分析**
- **正确答案**：一台业余中继台与一台由PTT键转换收发状态的业余对讲机之间的通信。  
- **错误选项解析**：  
  - 两台QSK CW收发信机属于全双工。  
  - 两台PTT对讲机为单工通信。  
  - 手机之间为全双工通信。  

**4. 引用知识库**
- 《中华人民共和国无线电频率划分规定》第1.5.12条明确半双工操作的定义，直接支持答案。  

**结论**
半双工操作的核心是“一端单工，另一端双工”。中继台（双工）与PTT对讲机（单工）的组合完美符合这一定义，而其他选项要么是全双工或单工通信。
