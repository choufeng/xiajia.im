# 说话练习

> 一个"边练边想"的栏目。每天开口一次，记下一段练习 + 背后的思考。
>
> 不追求播音腔，不追求标准口音。只追求：脑子里的话，能完整地说出来。

## 入门篇 · 十天路线

| 天 | 主题 | 练什么 |
|---|---|---|
| Day 1 | [先练什么](/speaking/01-day1-what-first) | 分层框架，先把"不断"练出来 |
| Day 2 | [卡住了怎么接](/speaking/02-day2-keep-going) | 复述 / 具体化 / 转向，三招救场 |
| Day 3 | [话多了怎么删](/speaking/03-day3-cut-the-fat) | 倒金字塔、压缩测试、逐句删 |
| Day 4 | [散句怎么排](/speaking/04-day4-find-the-order) | 主张 + 支撑，选一条线走到底 |
| Day 5 | [话不匀才有节奏](/speaking/05-day5-rhythm) | 停顿、重音、快慢 |
| Day 6 | [首尾怎么守](/speaking/06-day6-first-and-last) | 钩子开场、回收式收尾 |
| Day 7 | [例子怎么讲出画面](/speaking/07-day7-tell-a-story) | 暂停键、三个具体、行为代标签 |
| Day 8 | [从独白到对话](/speaking/08-day8-dialogue) | 丢路标、分类处理打断、主动开门 |
| Day 9 | [紧张来了怎么共处](/speaking/09-day9-nerves) | 提前泄压、慢启动、重新解读 |
| Day 10 | [九样东西拼成一段话](/speaking/10-day10-putting-it-together) | 一稿三遍、五格卡片、换听众 |

十天的顺序本身就是一个主张：先能说满，再能接上；先删再排，先骨架再节奏；守好门口，讲出画面；然后走出独白，带上紧张，拼成一段完整的、自己的话。

每一篇的末尾都有"最小练习"和"实录"——实录是留给自己填的，练完才填。
